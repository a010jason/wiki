# Alphabet Inc.

Google 2015 重組後的母控股公司；市值 \$475B（重組時）。HBS case 9-116-029（Robert Simons &amp; Annelena Lobb, Rev 2017）「Google to Alphabet」主角。教師核心 framing：「**Specialized generalist (Google) ↓ Generalized specialist (Alphabet)**」 — Alphabet 重組讓組織從「一專多能」變成「多專多能」。^[teacher-annotation]

> 教師對 Alphabet 結構本質的判斷：「**不是 Matrix，是 Google and non-Google**」 — Alphabet 不是真矩陣組織，是 Google + 非 Google 二元結構。^[teacher-annotation]

## 結構（Alphabet → Other Bets）

```
Alphabet Holdings
├── Google (Sundar Pichai)              ← 占整體營收絕大部分
└── Other Bets:
    ├── Calico (Arthur Levinson)        ← 抗衰老生物科技
    ├── DeepMind                        ← AI 研究
    ├── Fiber                           ← 光纖網路
    ├── Google Ventures (GV, Bill Maris)
    ├── Google Capital (David Lawee)
    ├── Google X (Astro Teller)         ← Moonshot Factory
    ├── Nest (Tony Fadell)              ← 智慧家居
    ├── Verily (Andy Conrad)            ← 醫療科技
    ├── Sidewalk Labs (Dan Doctoroff)   ← 智慧城市
    ├── Access &amp; Energy (Craig Barratt) ← 寬頻 + 再生能源
    └── Self-driving (John Krafcik)     ← Waymo

X Moonshots:
- Replicant (robots)
- Glass
- Project Loon (網路氣球)
- Project Wing (drone delivery 2017)
- Project Titan (high-altitude solar drones)
```

## Simons Stress-Test 7 Questions 框架

教師整套用 Robert Simons (HBR Nov 2010) 框架分析 Alphabet。詳見 stress test your strategy 7 questions。

| Q | 主題 | Alphabet 對應 |
|---|---|---|
| **Q1** | Allocating resources to customers | **users ≠ customers**（核心 trap） |
| **Q2** | Prioritizing Core Value | **政治家 vs 政客 / 投資 vs 投機** |
| **Q3** | Tracking Performance Goals | **KPI 低估 / OKR 管不了心 → 都是錯的** |
| **Q4** | Controlling strategic risks | **被抄越**（中國競品趕超） |
| **Q5** | Spurring innovations | **跨界創新 → 脫離舒適圈 → 平行競爭 → 負責任** |
| **Q6** | Building commitment | **Pride in purpose**（榮譽感 / 制度公平公正透明） |
| **Q7** | Adapting to change | **典範移轉 → Apple Car 撤案教訓** |

教師擴充 HBS case 為 8 問版本，含「primary customer at Google? functional structure with P&amp;L only at CEO level — appropriate?」等。

## Outside-In Strategy Cascade

教師反覆強調的核心框架（outside in strategy）：

```
價值主張 (Value Proposition)
  ↓
產業定位 (Industry Positioning)
  ↓
資源配置 (Resource Allocation)
  ↓
組織設計 (Organization Design)
```

對應 Q1 案例對標：LEGO（重新改變 value 從玩具 → 未來建築師）/ HTC Vive / Samsung / Acer / TSMC（engineering user solution vs marketing customers）。

## Google 2011 組織結構（HBS case 重點）

```
CEO
├── CFO
├── People Operations
├── Engineering-based Product Groups
│   ├── Search
│   ├── Ads
│   ├── Mobile
│   ├── YouTube
│   ├── Chrome
│   └── Maps
└── Marketing &amp; Sales
```

教師眉批：「**沒有財務 → No P&amp;L / By business unit or functions or matrix?**」 ^[teacher-annotation]

**No P&amp;L by product group** — 全部歸 CEO level。對應 HBS case Q2「functional structure with P&amp;L only at CEO level — appropriate?」的質疑。

## OKR Superpowers（Doerr）

教師明點對 Alphabet 為何 went wrong 的質疑：「**Why all these superpower 為什麼 went wrong in Alphabet?**」 ^[teacher-annotation]

四項 superpower：
1. **Focus and Commit to Priorities**
2. **Align and Connect for Teamwork**
3. **Track for Accountability**
4. **Stretch for Amazing**

Larry Page 引言：「OKRs have helped lead us to 10x growth, many times over.」

但教師補充：「**Why employee OKR might be GIGO 第一世界、第二世界的問題 → AMAZON (沒有人敢小便)**」 — OKR 在不同文化情境下會 garbage-in-garbage-out；Amazon 強壓力文化下員工不敢偷懶反例。^[teacher-annotation]

## Larry Page 2014 自評

「**I think we've not succeeded as much as we'd like.**」（Bloomberg 2015-08-11「Do You Trust Larry Page?」）

對 mission statement 是否需更新：「I think we do, probably. We're still trying to work that out.」 — **Mission drift** 警訊。

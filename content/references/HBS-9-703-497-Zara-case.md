## 教師眉批採集（核心）

### 象數理 epistemology（最珍貴 — 教師原創跨領域對接）

> 「**Epistemology 認識論（知識論）/ Prediction**」
> 「**Calculation is straightforward（數）**」
> 「**Interpretation requires judgment（象）**」
> 「**Judgment is sharpened by experience（理）**」
> 「**陰陽五行即是「象、數、理」。**」
> 「**凡事有定，定中有象，象中有數，數中有理。**」
> 「**Note: Popper's three worlds**」

### 戰略觀點

> 「**天下武功，唯快不破**」（封面）
> 「**Sustainability → 等死、找死**」
> 「**SHEIN vs Zara：半價以下！抄抄抄**」
> 「**COVID-19 為什麼沒有影響？2012 online**」
> 「**Backward Integration / Forward Integration / 垂直整合 / 快速就來自 Vertical integration**」
> 「**Zara 200 個設計師，每年從 40,000 件新品選出 10,000 件 / 10,000/50 wk = 200/wk**」
> 「**Why Zara insist 在西班牙？→ C.O.O / S.C.M / FAST**」
> 「**為什麼要設在貴的地方 → 不用廣告 / 同樣式但較便宜 → 交給高級品牌廣告（寄生）**」
> 「**Achieve Zero Inventory**」
> 「**Store Manager (+科技) 掌控垂直整合的運轉 → Store Manager 連結市場和工廠**」
> 「**全部都可以被學 → 但合起來學不來 / Zara Psychology / 生產 Push Marketing**」
> 「**輕資產 / Working Capital（營運資金）很低 → 投資在 Retail、資訊**」
> 「**因緣成果：目標 → 價值觀 → 績效**」
> 「**5 種 pre-MFA 成長路線：頂客族 / 夥伴聯盟 / 媒體投資 / 空手道 / 國際套利 — Zara 這 5 個都不是**」（即 6th way）

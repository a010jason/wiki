# Disruptive Innovation × VRIO Framework

## The Connection

兩個框架同時嘗試回答「為什麼有些公司贏」，但給出**互斥的時間預設**：

- **[[concepts/VRIO-framework|VRIO]]（Barney 1991, RBV 母框架）**：靜態 snapshot — 此刻的 Valuable / Rare / Inimitable / Organized 資源 → sustained advantage
- **[[concepts/disruptive-innovation|Disruptive Innovation]]（Christensen 1997）**：動態流程 — 同一個 VRIO-passing 資源在新典範下變成 liability，incumbent 因「Organized」而僵化

→ VRIO 說「找到 Inimitable 資源就贏」；Christensen 反駁「Inimitable 資源 = 難改變 = 被新典範淘汰的原因」。^[inferred]

## Where They Co-occur

6 個 wiki 頁同時引用兩者：

- [[concepts/RPV-framework]] — Christensen 自己對 VRIO 的回應：Resources / Processes / **Values** 三層，Values 最難改（攻 VRIO 的「Organized」維度）
- [[concepts/tautology-in-management-theory]] — 唐瓔璋 SMJ 2010 論戰：VRIO 與 Disruption **都**是 tautology
- [[references/fighting-with-porter-lecture]] — 哲學層級攻擊
- [[references/grant-contemporary-strategy-analysis]] — 教科書並陳兩派

## Cross-cutting Insight

**VRIO 與 Disruption 對「Inimitable」的判斷剛好相反**：

| 維度 | VRIO 視角 | Disruption 視角 |
|---|---|---|
| Inimitable 資源 | 競爭優勢的核心 | **核心剛性**（core rigidity）— Leonard-Barton 1992 |
| Organized | 把資源 deploy 成 value 的能力 | 對既有客戶的承諾 → 拒絕低端市場（Christensen 1997） |
| 時間軸 | 「持續」= 多年穩定 | 「持續」= 直到新典範出現 |
| 失敗模式 | 缺 VRIO 條件就輸 | **VRIO 越完美越死得快**（Kodak / Blockbuster） |

→ 對 incumbent 來說，**最危險的時刻是 VRIO score 最高的時刻**。^[inferred]

[[concepts/RPV-framework|RPV]] 是 Christensen 為這個矛盾寫的橋樑：Resources（可換）/ Processes（中等難）/ Values（最難改）— 把 VRIO 的「Organized」剝開，指出 Values 才是 incumbent 不能 pivot 的真正原因。

## Tensions and Trade-offs

### 1. RBV 的靜態 vs Disruption 的動態

VRIO 是 1991 年 Barney 對 1980s I/O 學派（Porter）的回應，提供企業內部視角 — 但**沒處理「環境變化使 VRIO 失效」的情境**。Disruption 直接填這個洞。^[inferred]

→ [[concepts/dynamic-capabilities|Dynamic Capabilities]]（Teece）是另一條後續路線：把「持續 reconfigure 能力」本身視為 VRIO 資源。但這條路線**沒被 VRIO 教科書整合**。

### 2. 兩者皆被質疑 tautology

[[concepts/tautology-in-management-theory|唐瓔璋 SMJ 2010 論戰]]指出 VRIO 與 Disruption **都**是恆真句：

- VRIO：「Valuable + Rare + Inimitable + Organized → 持續優勢」← 但 Valuable 等於「能帶來優勢」、Inimitable 等於「對手做不到」— 邏輯上不可證偽
- Disruption：「低端切入 → 向上侵蝕」← 但「被侵蝕的」回頭被定義為 disruption 對象，「沒被侵蝕的」歸為「不是真 disruption」

→ Karl Popper 的 [[concepts/falsifiability-popper|falsifiability]] 標準下，兩個框架都不算 science。^[ambiguous]

### 3. 經驗反例兩邊都有

- **VRIO 反例（incumbent 維持優勢）**：Apple iPhone（不只 disrupt 別人也防 disrupt 自己）/ Amazon AWS（incumbent 自己孵 disruption）/ TSMC（垂直深化的 Inimitable 反而抗 disruption）^[inferred]
- **Disruption 反例**：Lepore 2014 / King-Baatartogtokh 2015（HBR 9% conformance rate）/ iPhone 高端 disruption（Christensen 2006 HBR 自己承認反例）

→ 兩個框架都不具有預測力，只有 ex post 解釋力。教科書教學要小心。

## Open Questions

- **VRIO 是否能修補為動態？** 若把「持續 reconfigure 能力」本身視為 VRIO 資源，就能涵蓋 dynamic capabilities — 但這會讓 VRIO 變成 tautology 的另一形式（持續優勢 → 因為有持續優勢能力）。
- **「Inimitable」是否該分「結構 inimitable」vs「文化 inimitable」？** RPV 的 Values 路線指向後者；VRIO 教科書沒區分。
- **GenAI 時代 VRIO 的「Rare」是否失效？** 演算法、模型、資料可被多家同時取得，但 fine-tune / RLHF / 場景 know-how 仍稀缺 — VRIO 該怎麼套？

# Blue Ocean × Disruptive Innovation

## The Connection

兩個 1990s-2000s 的「創造新市場」理論常被學員混為一談。實務上**兩者描述兩條完全不同的軌跡**：

| 維度 | Blue Ocean（Kim & Mauborgne 2005） | Disruptive Innovation（Christensen 1997） |
|---|---|---|
| **起點** | 既有市場「之外」 | 既有市場「之下」（低端 / 被忽略） |
| **方向** | **橫向**跨類別重組屬性 | **垂直**從低端向上侵蝕 |
| **對 incumbent** | 不直接競爭、被忽略 | 直接威脅、最後被取代 |
| **客戶** | 新客群 + 跨類別客群 | 既有產業的次等客戶 → 主流客戶 |
| **價格定位** | 通常高端（重新定價） | 通常低端起步 |
| **競爭框架** | 取消 / 提升 / 降低 / 創造 4 動作 | 從次等市場切入 + 慢慢爬升 |
| **代表案例** | Cirque du Soleil、iPad、Yellow Tail Wine | Netflix vs Blockbuster、Kindle vs 紙書、Honda 機車 vs Harley |

→ Grant Ch7 把兩者都歸為 **strategic innovation** 的子型，但**沒明說它們是「對偶」軌跡** —— 本頁的核心 insight。^[inferred]

## Cross-cutting Insight

**兩條相反的軌跡 → 同一目的地（uncontested market）**：

```
                ╔═══════════════════════════════╗
                ║   Uncontested Market Space   ║
                ║   （沒有 competitor 的市場）       ║
                ╚═══════════════════════════════╝
                          ↑      ↑
                          ║      ║
         Blue Ocean ━━━━━━┛      ┗━━━━━━ Disruptive
         （橫向跨類別）                       （垂直爬升）
              ↑                              ↑
              │                              │
         既有市場外                          既有市場內低端
```

**對 incumbent 來說，兩個策略的「威脅性」完全不同**：

| 對 incumbent 的影響 | Blue Ocean | Disruptive |
|---|---|---|
| **被察覺速度** | 慢（不同類別、新客群） | 中（同產業但低端） |
| **直接競爭** | 不直接 | 直接（最後接管主流客戶） |
| **incumbent 的合理反應** | 忽略（"不是我們的市場"） | 加強既有客戶服務（"我們已經贏了") |
| **incumbent 的失敗模式** | 錯過跨類別機會 | Innovator's Dilemma |
| **修復難度** | 中（可後進） | 高（[[synthesis/corporate-venturing-isolation-paradox]]） |

—— **Blue Ocean 對 incumbent 是「機會錯失」、Disruptive 對 incumbent 是「結構崩壞」**。後者比前者致命。^[inferred]

## 為何兩者都「事後合理化」風險高

兩個概念都有同樣的批評：**survivorship bias**。

- Cirque du Soleil 成功了 → 被稱為 Blue Ocean；無數試圖跨類別創新失敗的案例**沒被記錄**
- Netflix 取代 Blockbuster → 被稱為 Disruptive；無數試圖 low-end 切入失敗的案例**沒被記錄**

→ 兩個框架**事後解釋力 ≠ 事前預測力**。Strategy Canvas 與 Innovator's Dilemma 都更像「贏家事後說的故事」。^[ambiguous]

但兩者**揭示的反直覺真相**仍有用：

- Blue Ocean 提醒：**競爭最激烈的市場不一定要打** — 跨類別重組屬性是合理選擇
- Disruptive 提醒：**最賺錢的客戶不一定該服務到底** — overshooting 是失敗起點

—— 即使預測力有限，**框架本身仍是有用的反直覺對沖**。^[inferred]

## Tensions and Trade-offs

### Tension 1：Blue Ocean 高端 vs Disruptive 低端

兩個框架都教「不要直接競爭」，但建議的方向**完全相反**：

- Blue Ocean：**往上 / 跨**（重新定價 + 新屬性 + 新客群）
- Disruptive：**往下 / 內**（低端 + 被忽略客戶 + 較低品質）

→ 一個業者如果同時聽兩個框架的建議會精神分裂。實務應該**先判斷市場結構**：

| 市場條件 | 適用框架 |
|---|---|
| 既有業者過度服務高端、低端被忽略 | Disruptive（從低端切） |
| 既有業者鎖在固定屬性組合、有大量「非消費者」 | Blue Ocean（跨類別） |
| 既有業者覆蓋全面、無明顯弱點 | 兩個都難 — 找 dynamic capability 或退場 |

### Tension 2：「不直接競爭」的可持續性

Blue Ocean **本身定義**就是不可持續 — 一旦成功，competitor 跟進，藍海變紅海。Kim & Mauborgne 後來補了「Blue Ocean Imitator's Trap」說這要持續創新。

Disruptive 反而**結構性可持續** — 從低端切入後，incumbent 因為 RPV / Innovator's Dilemma 結構性無法回應，window 可達 5-10 年。

→ **Disruptive 的窗口比 Blue Ocean 長**。但 Disruptive 的進入難度（要建立完整 low-end product）也比 Blue Ocean（一次屬性重組）高。^[inferred]

### Tension 3：兩者對 incumbent 的「建議」相反

如果你是 incumbent，兩個框架給的建議：

- Blue Ocean：**主動開新類別**（Cirque du Soleil 是 Bouglione Circus 創辦的對手 — 不是被 incumbent 開的）— **incumbent 結構上做不到**
- Disruptive：**做 spinoff** + RPV 的 Values 隔離（C 象限）— **incumbent 也做不到**（[[synthesis/corporate-venturing-isolation-paradox]]）

→ 兩個框架都隱含「incumbent 不能自救」的結論。^[inferred]

## 在醫療 AI 的判讀

EBM 該走哪條路？

**Disruptive 路徑**：
- 從**小診所 / 健檢中心**切入（incumbent Sectra / GE / Philips 不重視）
- 用較低品質 / 較便宜 / 較少功能的 cloud PACS
- 慢慢爬到中型醫院、大型醫院
- 風險：醫療業切換成本極高、法規進入障礙高，**low-end 切入的「無 switching cost 客戶」其實很少**

**Blue Ocean 路徑**：
- 跨類別重組：把 PACS 與 EMR / RIS / LIS / Wearable / 居家照護 重新組合成新類別
- 例如：**AI 為核心的 longitudinal patient health view**（不是影像 + 報告，而是時間軸 + 多模態）
- 風險：跨類別創新的合規路徑不清，FDA 與 TFDA 不知道怎麼分類

→ 兩個都有結構性難度。**醫療 AI 的「藍海」其實是被法規 + dominant design 鎖在紅海** —— 這是醫療業 disruption / blue ocean 都比消費網路慢的根本原因。^[inferred]

## Open Questions

- **AI-Native 醫療 軟體是 Blue Ocean 還是 Disruptive？** 它取消（hanging protocol）+ 提升（自然語言 report）+ 創造（agentic workflow） — 像 Blue Ocean；但它從**較簡單的 use case 切入後爬升** — 像 Disruptive。是否兩者並存？
- **失敗案例的 base rate**：Blue Ocean / Disruptive 失敗案例 base rate 如何？學界傾向給成功案例，缺乏反例研究
- **平台型產業是否打破兩個框架？** 平台 (Airbnb / Uber / TikTok) 既橫向跨類別又向上侵蝕既有業者 — 是 Blue Ocean + Disruptive 的混血嗎？

# 財報詮釋的 Epistemology — 象數理 ↔ Popper 三世界

**教師原創跨領域 epistemology synthesis**（[[references/HBS-9-703-497-Zara-case|Zara lecture]] Reading Financial Ratios slide）。把財報分析的三個層級對應到：
1. **陰陽五行的「象、數、理」**（中國古典 epistemology）
2. **Karl Popper 的「Three Worlds」**（西方哲學 epistemology）

— 是 Jason wiki 內最跨領域的 epistemology synthesis 之一。^[teacher-annotation]

## 教師原話（核心 quotes）

> 「**Epistemology 認識論（知識論）/ Prediction**」
> 「**Calculation is straightforward（數）**」
> 「**Interpretation requires judgment（象）**」
> 「**Judgment is sharpened by experience（理）**」
> 「**陰陽五行即是「象、數、理」。**」
> 「**凡事有定，定中有象，象中有數，數中有理。**」
> 「**Note: Popper's three worlds**」 ^[teacher-annotation]

## 三層對應表

| 層級 | 內涵 | 陰陽五行 | Popper World | 財報層級 |
|---|---|---|---|---|
| **數** | Calculation is straightforward | 五行的「行」 / 數字本身 | **World 1** — 物理事實 | ROE / ROA / Margin 數字 |
| **象** | Interpretation requires judgment | 五行的「象」（卦象/形象）| **World 2** — 主觀心理 | 數字背後的業務故事 |
| **理** | Judgment is sharpened by experience | 五行的「理」（道理/規律）| **World 3** — 客觀知識體 | 跨脈絡跨產業的洞察 |

## 邏輯遞進關係

教師命題：「**凡事有定，定中有象，象中有數，數中有理。**」

```
凡事有定（任何現象都有規律性）
   ↓ 定中有象（規律呈現為現象）
   ↓ 象中有數（現象可量化）
   ↓ 數中有理（數字背後有道理）
```

學習路徑（逆向）：**數 → 象 → 理**（從計算到詮釋到判斷）

## Zara 案例驗證（教師主例）

| Zara 財報觀察 | 數（World 1） | 象（World 2） | 理（World 3） |
|---|---|---|---|
| Operating margin 21.66% vs Gap 2.44% | 21.66% / 2.44% | Zara 比 Gap 賺更多 | 垂直整合 + Quick Response 是高 margin 根源；不是 fast fashion 普遍規律 |
| Inventory 少 50% | 50% | 庫存效率高 | Achieve Zero Inventory；6 件 / 款 freshness + scarcity 心理 |
| Advertising 0.3% vs 業界 3.1% | 0.3% / 3.1% | 不做傳統廣告 | 大店 + 貴地段 = word-of-mouth + 寄生高級品牌廣告 |
| 76% 股票市值反映未來成長期望 | 76% | 股價遠高於 earnings | 市場相信 Zara fast fashion 可持續；可能也是泡沫風險 |

教師核心眉批：「**全部都可以被學 → 但合起來學不來 / Zara Psychology**」 — **理**的層級是 capabilities bundle 的 emergent property，無法被分解複製。^[teacher-annotation]

## Popper Three Worlds（西方版本）

Karl Popper（1972）三世界框架：

### World 1 — Physical World
- 物理對象、能量、物質狀態
- 對應財報：**數字本身**（balance sheet 的 cash \$1,694M 是物理事實）

### World 2 — Subjective World
- 個人心理狀態、知覺、信念、感受
- 對應財報：**分析師的詮釋**（為什麼 ROE 22.88% 是好 — 個人心理 + framing）

### World 3 — Objective Knowledge
- 客觀知識體：theories, books, scientific propositions, abstract objects
- 對應財報：**累積的產業智慧**（fast fashion 的 vertical integration logic 是 World 3 知識）

關鍵：**World 3 是 emergent**（從 World 2 的人類心智活動產生，但成為獨立存在的客觀知識體）— 對應「理」的累積性 + 可獨立傳承性。

## 為什麼這個跨領域對接重要

### 1. East-West epistemology 對接的稀有案例
- 中國古典 epistemology（陰陽五行 / 易經）vs 西方分析哲學（Popper）少有直接對接
- 教師明點「**陰陽五行即是「象、數、理」/ Note: Popper's three worlds**」 — 是 deliberate cross-domain mapping

### 2. 修正 MBA 過度量化偏好
- MBA 訓練多偏「數」（Excel modelling、DCF 計算）
- 教師明點要從「數」往「象」「理」走
- 對 PM 工作：dashboard / KPI 是「數」；用戶訪談 / 質性洞察是「象」；策略判斷 / 產業paradigm 是「理」

### 3. 解釋為什麼 capabilities bundle 不可模仿
- Zara「全部可學但合起來學不來」 = **理層級的整合無法被分解**
- Booking A/B testing 文化也是同道理 — capability bundle 是 World 3 emergent property
- 連結 [[concepts/dynamic-capabilities]]（Teece 1997）的 co-specialized assets 論點

### 4. 教學節奏
- 給中文背景學員一個熟悉的 anchor 理解 financial ratio analysis
- 與其他古典管理對接形成系列（[[synthesis/wei-zheng-leadership-and-subsidiary-management|諫太宗十思疏]] / [[synthesis/yoffie-five-rules-vs-sun-tzu-five-fundamentals|孫子兵法五事]]）

## 跨領域延伸（推測）^[inferred]

「象數理」可套用其他資訊分析場景：

### 醫療 AI（Jason 視角）
- **數**：Sensitivity / Specificity / AUC / DICE score
- **象**：醫師如何 trust AI 結果 / clinical workflow integration
- **理**：醫療業 ESG 監管走向 / patient outcome 累積知識

### PM 工作
- **數**：DAU / ARPU / retention / NPS
- **象**：用戶訪談 / journey map / personas
- **理**：產業 paradigm shift / 競爭格局 / 商模演化

### A/B Testing
- **數**：p-value、conversion lift、CTR
- **象**：為什麼用戶這樣選 / hypothesis 真假
- **理**：何時 A/B 不適用（[[concepts/ab-testing-as-strategy]]）；為何 Villas.com 失敗

### Strategy Cases
- **數**：market share / margin / growth rate
- **象**：戰略意圖 / vision / leadership style
- **理**：產業 paradigm / capability bundle / Icarus paradox

## 反例 / 邊界條件

### 教師原話出處不明
「**凡事有定，定中有象，象中有數，數中有理。**」教師標示但**未引出處**：
- 可能是《易經·繫辭》「太極生兩儀，兩儀生四象」延伸
- 可能是《道德經》「道生一，一生二」延伸
- 可能是教師自創 ^[ambiguous]

### 嚴格學術對接的問題
- 陰陽五行不是嚴格 epistemology（更像 ontology / cosmology）
- 把「象 = World 2」「理 = World 3」是 stretch — Popper World 2 是主觀心理，「象」是現象（接近 World 1 + 2 之間）
- 「數 = World 1」也不完全準確 — 數字是 World 3 abstract object 不是 World 1 physical state

### 文化包袱
- 對非中文背景學員，陰陽五行可能像神秘主義
- 硬接 Popper 可能被批 epistemologically incoherent ^[inferred]

### 西方其他對應框架
- **Aristotle 三分**：epistēmē（科學知識）/ technē（技藝）/ phronēsis（實踐智慧）— 更接近 數 / 象 / 理 的線性遞進
- **Polanyi 1958**：explicit knowledge / tacit knowledge — 對應 數 vs 理
- **DIKW pyramid**（Data / Information / Knowledge / Wisdom）— 4 層而非 3 層
- 「象數理」3 層 vs DIKW 4 層 — 哪個更精確？^[inferred]

## Jason 的判斷（confidence: medium）

教師的跨領域對接**有啟發但需限定使用範圍**：

✅ **適用**：
- 給中文背景學員 anchor 加速理解 financial ratio analysis
- 強調 interpretation over calculation（從「數」往「象」「理」走）
- 解釋為什麼 capabilities bundle 不可模仿（理層級的 emergent property）

⚠️ **不適用**：
- 嚴格 epistemology 學術討論（象數理與 Popper 對接不完美）
- 直接從「象數理」推 financial ratio interpretation 方法論（教師未給具體 SOP）
- 跨文化非中文背景對話（文化包袱大）

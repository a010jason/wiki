# HTC 行銷研究缺口

## 為什麼 HTC 案例值得 synthesis

教師在 Kotler Ch01 / Ch07 / Ch08 三個章節都用 HTC 為失敗案例，三層解釋連起來 = **完整 marketing failure 拼圖**：

1. **Ch01** — Customer centricity 失敗：「出貨給 Carrier 不是 End User」
2. **Ch07** — Positioning 失敗：「Quietly Brilliant 缺 aspirational quality」
3. **Ch08** — Product differentiation 失敗：「機海戰術陷入 #3-9 lowest common denominator」

本頁把三層整合為單一 case study。

## Layer 1 — Customer Centricity 失敗（Ch01）

教師批註：「Which function is lacking for FAE (in Taiwan)? **HTC vs Samsung**? **End User (customers)**? **HTC 是出貨給 Carrier**」。^[inferred from instructor annotation Ch01 p.33]

### 機制
HTC 是出貨給 carrier（中華電信、AT&T、Verizon 等通路）而不是 end user 的商業模式。Carrier 是 buyer，end user 是 user — 兩個不同 stakeholder。

意涵（連結 [[concepts/buying-center]]）：
- HTC 把 **Buyer**（Carrier）視為唯一 customer
- 忽略 **User**（手機購買者）的 voice
- 失去 [[concepts/customer-centricity]] 的 outside-in 視角

### 對比：Samsung
Samsung 從面板（B2B）到品牌（B2C）一體化，**同時服務 carrier 與 end user**，所以 marketing research 投入到 end user — Samsung 有充足的消費者研究能力 / 預算。

## Layer 2 — Positioning 失敗（Ch07）

教師批註：「**Lowest common denominator "mass targeting" lacks "aspirational"**」「**hTC quietly brilliant**」。^[inferred from instructor annotation Ch07 p.24]

### 機制
"Quietly Brilliant" 是 HTC 著名的品牌 slogan，但教師指出：
- 試圖 mass targeting（大眾化定位）
- 結果落入 lowest common denominator
- 失去 aspirational quality（與奢侈品 / 高端品牌相反）

意涵（連結 [[concepts/positioning]]）：
- HTC 的 [[concepts/frame-of-reference]] 是「智慧型手機通用品牌」 — 跟全世界比
- 在這個 FOR 內缺 [[concepts/points-of-difference-and-parity]] POD（沒有 desirable + deliverable + differentiating 的 attribute）
- 對比 Apple "Think Different"（high aspirational）/ Tesla（high aspirational）

### Acer "Proud to Serve" 同類錯誤
教師同列 Acer："Proud to serve, Proud of Acer" — 同樣 mass targeting / lacks aspirational，被歸為 [[concepts/marketing-orientations]] 中 Selling concept 的代表。^[inferred from instructor annotation Ch01 p.29]

## Layer 3 — Product Differentiation 失敗（Ch08）

教師批註：「**機海戰術 Failed**」「**Customized for vendors rather than end users**」「**Brand equity "leveraged" by AT&T, Beats, and Evernote**」。^[inferred from instructor annotation Ch08]

### 機制
HTC 的「機海戰術」 = 在 [[concepts/product-differentiation-9-dimensions]] 的 #2 Features 上窮舉，推出大量 SKU 涵蓋市場各價位段。

但是：
- 在 **#1 Core functionality** 上沒重新定義
- 在 **#3-9（Performance / Conformance / Durability / Reliability / Form / Style / Customization）** 上競爭，這些是 lowest common denominator
- **#2 Features 變成累贅而非優勢** — [[concepts/features-fatigue]]

對比 Apple：在 #2 Features 上做減法（簡化），同時在 #1 Core functionality 上重新定義（智慧型助理）。

### 「Brand equity leveraged」
HTC 與 AT&T、Beats、Evernote 合作 = 把 brand equity 借給 partner，但 partner 拿走 brand 資產（end user 認 Beats / AT&T 而非 HTC）。

## 三層整合：完整 marketing failure 機制

```
[Customer centricity 失敗 (Ch01)]
    Carrier 視為 customer，end user 視角缺失
                ↓
[Positioning 失敗 (Ch07)]
    沒 end user research → 不知道 FOR 該設哪
    → Mass targeting → Lowest common denominator
                ↓
[Product differentiation 失敗 (Ch08)]
    沒 positioning 銳利度 → 用機海戰術補
    → 落入 #3-9 工程指標
    → Brand commoditize 給 carrier
                ↓
[結局：HTC 從 2011 高峰跌入 2016 谷底]
```

## 與台灣電子業整體的對應

教師批註多次擴大到台灣電子業：^[inferred from instructor annotation]

- 「Taiwan OEM/ODM **miss all three POD criteria**」（[[concepts/points-of-difference-and-parity]] 的 desirable / deliverable / differentiating 全 fail）
- 「電子五哥」案例同類錯誤

意涵：HTC 不是孤立失敗，是台灣電子業集體結構性問題的代表。

## 對 EBM 醫材 PM 的 lesson

雖然 EBM 在不同行業，但**同型風險存在**：^[inferred — Jason 個人延伸 / visibility-consideration: internal candidate]

### 高風險 pattern：
- 把 **PACS vendor**（Sectra / GE）視為唯一 customer → 失去**醫師 end user** 視角 = HTC pattern
- 與 PACS vendor 共同提案，brand 被 PACS vendor leverage = HTC pattern
- 模型 # 多但每個都 me-too = 機海戰術 = HTC pattern

### 低風險 pattern：
- 同時做 **PACS vendor 整合**（buyer）+ **醫師 KOL 關係**（user）
- 在 #1 Core functionality 上重新定義（「臨床流程加速器」而非「AI 模型」）
- 推出少數 sharp positioning 的旗艦產品 vs 全 modality 覆蓋

關鍵：**EBM 不能成為「醫療版 HTC」**。

# Back-to-Core Turnaround Pattern

[[entities/Apple]] 1997 / [[entities/Lego-Group|Lego]] 2004 / [[entities/Samsung-Electronics|Samsung]] 1997 三個成功 turnaround 的 cross-case pattern 分析。^[Jason synthesis]

> 共同核心模板（教師 Lego 講義原話）：「**re-position → re-configuration → removes the barrier of mobility → re-inventing value chain**」 ^[teacher-annotation, [[references/HBS-9-713-478-Lego-crisis-case]]]

## 三案 side-by-side 對比

| 維度 | Apple 1997 (Jobs) | Lego 2004 (Knudstorp) | Samsung 1997 (Yun) |
|---|---|---|---|
| **危機程度** | 瀕臨破產（Q1 1997 loss \$740M） | 瀕臨破產（2004 net loss DKK -1.9B） | 1997 亞洲金融風暴；債務 \$15B / 淨利 -\$1.6B |
| **接班人** | Jobs 回鍋（外部多年） | Knudstorp 36 歲外部顧問 | Yun 接副董事長 |
| **Re-position** | PC → consumer electronics + design DNA | 多角化 → plastic-brick 核心 | 三流 OEM → high-value brand |
| **Re-configuration** | 砍產品線（2×2 矩陣）；Ive 搭檔 | 砍 SKU 12,000+；內化外包；AFOL 社群 | 砍 29,000 員工；賣 \$2B 資產；GMO 整合 |
| **Mobility barrier removed** | 接受砍掉 Apple Computer 歷史 | 接受家族企業犧牲不可侵犯之物 | 接受垂直整合 + 反外包潮 |
| **Value chain reinvention** | 1998 iMac → 2001 iPod → Digital Hub → 2007 Apple Inc. | AFOL + Disney/Star Wars licensing + LEGO Movie | 客製化晶片 +17% 溢價；Sashimi 5 月 cycle；DigitAll |
| **Time-to-result** | 4 年（1997→2001 iPod） | 6 年（2004→2010 利潤恢復） | 5 年（1997→2002 黑字） |
| **量化結果** | 市值 → \$619B 史上最有價值 | Brand value \$2B → \$7.5B | 股價 10x、市值 \$41B 亞洲最大 |

## 共同 Pattern 5 條（synthesis 主張）

### 1. 「犧牲不可侵犯之物」是 unlock 條件

教師 Lego 講義眉批：「**犧牲一些『不可侵犯之物』→ 家族企業**」 ^[teacher-annotation]

- **Apple**：犧牲「Apple Computer」歷史 — 2007 改名 Apple Inc.
- **Lego**：犧牲家族企業遺產 — 36 歲外人 CEO + 變賣 LEGOLAND（Christiansen 家族 36% 持股仍續，但 control 讓出）
- **Samsung**：犧牲韓國「面子」— Yun 公開承認三流品牌身份，1993 Lee Frankfurt 宣言

**Pattern**：不能保留「神聖的」legacy；turnaround 本質是 sacrificial。

### 2. 外部視角 CEO 或 de facto 外人

- Jobs 雖然 founder 但 1985-1997 被董事會邊緣化 = **de facto 外人**
- Knudstorp 顧問背景、36 歲完全 outside
- Yun 雖內部接班但**經歷 1997 危機 + 願意做反主流 vertical integration** = **思維 outside**

**Pattern**：純 internal succession 多失敗（HP / Yahoo 多任 CEO）；turnaround 需要 outside perspective 重設 capability。

### 3. Re-position 必經「2×2 矩陣級」極端 focus

- Apple：白板 2×2 矩陣（4 格 product line）
- Lego：plastic-brick 核心（砍多角化）
- Samsung：垂直整合反外包（單一戰略方向）

**Pattern**：再生期的 product / brand portfolio 比 normal 期窄 70-90%。

### 4. Mobility barrier removal = 換 leadership 或政治處置

- Apple：Sculley / Spindler / Amelio 三任 CEO 離開
- Lego：Ploughmann 退；接受 [[concepts/subsidiary-leader-lifecycle|Local Baron]] 處置
- Samsung：1997 砍 29,000 員工（含 mid-management 老人）

**Pattern**：不換掉舊勢力，re-configuration 就被反撲。

### 5. Value chain reinvention 走「不同維度」而非「優化舊維度」

- Apple：從 PC 跳到 consumer electronics（Digital Hub 是**新維度**）
- Lego：從玩具產品跳到 entertainment ecosystem（AFOL + 電影 + 樂園是**新維度**）
- Samsung：從 OEM 跳到 vertical brand + GMO（**新維度**）

**Pattern**：不是把舊產品做得更好，是**跳到新 value chain dimension**。

## 為什麼這個 pattern 重要

### 1. 解釋為什麼多數 turnaround 失敗
教師暗示的失敗模式（Lego 1999-2004 Ploughmann 期）：

- **跳過 re-position 直接 cost-cut**（砍裁員不砍 strategy）
- **保留 founder / family CEO**（Mobility barrier 無法移除）
- **「Managing for Growth」太早**（cash burn 加速死亡）
- **多角化 explore 期不收斂**（[[concepts/sku-proliferation-trap]]）
- **無外部視角**（內部 CEO 看不到 [[concepts/icarus-paradox|Icarus paradox]]）

### 2. 跨產業普適性
三案橫跨：
- 電子消費品（Apple）
- 玩具（Lego）
- 半導體 + 家電（Samsung）

→ 不是產業特定，是**組織 / leadership 通用模板**。

### 3. 連結 [[concepts/organizational-ambidexterity|ambidexterity]]
- Turnaround 期是**極度 exploit**（先活下來）
- 不能同時 explore（[[concepts/sku-proliferation-trap]] 警示）
- Apple / Lego / Samsung 都先收斂 1-2 年再擴張

### 4. 連結 [[concepts/icarus-paradox|Icarus paradox]]
三案都是 Icarus paradox 的 escape examples — 證明 paradox 不是死局。
- Icarus 解釋為什麼 incumbent 會墜落
- Back-to-core pattern 解釋怎麼從墜落中爬起

### 5. 對醫療 AI 的啟示（Jason 視角）^[inferred]
EBM 等中等規模醫療 AI 公司若遇危機，可參考三案 pattern：
- Re-position：聚焦 1-2 個 FDA-cleared use case 而非多模態
- Re-configuration：砍 R&amp;D 嘗試項目，內化 PACS 整合 capability
- Mobility barrier：換掉 sales / leadership 中 legacy 思維
- Value chain reinvention：從點工具 → workflow integration → reimbursement code 完整 chain

## 反例：不適用的 turnaround 案例

### 純粹 cost-cut turnaround（非 back-to-core）
- **HP Carly Fiorina / Mark Hurd 1999-2010**：多次嘗試但未完全 turnaround；分拆 HP Inc. + HPE 2015 才達到部分 re-position；缺乏 sacrifice + outside perspective
- **Yahoo Carol Bartz / Marissa Mayer / Tim Armstrong**：reposition 嘗試失敗；mobility barrier 移除失敗（每任 CEO 都被舊董事會綁手綁腳）

### 規模太大難以 back-to-core
- **GE Jeff Immelt 2001-2017**：規模太大、多元事業群、failed to identify "the core"
- **IBM Sam Palmisano → Ginni Rometty**：cloud pivot 太晚、太散

### Regulatory-forced restructuring（非 voluntary turnaround）
- **[[entities/Ant-Group]] 2020 IPO halt 後**：被監管強制重組為金融控股 — 不是主動 back-to-core
- 框架不完全適用

### 已死的 turnaround 嘗試
- **Polaroid / Kodak / Blockbuster / Sears**：[[concepts/icarus-paradox]] 確實是死局；back-to-core pattern 來得太晚或執行失敗

## Microsoft 2014-2024 Nadella — 變體 pattern

[[entities/Microsoft]] Nadella 接 CEO 後 cloud-first turnaround **不完全符合**本 pattern：

- ✅ Re-position：Windows 為中心 → Cloud + Platform
- ⚠️ Re-configuration：**沒裁員**、**沒砍 product**，是 capability shift（不同維度的 turnaround）
- ✅ Mobility barrier removed：換掉 Ballmer + 部分高管
- ✅ Value chain reinvention：Azure + Teams + GitHub + Copilot

教師暗示這是「**不可侵犯之物**」更隱性的版本 — Nadella 沒砍 Windows / Office，但**砍掉「我們是 desktop OS 公司」的 self-identity** — Mindset 級 sacrifice 而非 asset 級 sacrifice。^[inferred]

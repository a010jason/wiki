## TL;DR

雇主品牌 = **員工真實體驗 + 組織期望與承諾表達**。在求才難年代，企業需透過建構雇主品牌吸引並留住人才。[[entities/Huang-Bo-Xiang]]（[[entities/Tymphany]] 人資長）2025 課程提出「真實雇主品牌四要素金字塔」與「吸引人才五大構面」框架。

## 四要素金字塔

```
       體驗 (Experience)
              ↑
       員工 (Employee) ← 核心
       ↗            ↖
期望 (Expectation)  表達 (Expression)
```

## 吸引人才五大構面

5 個面向相互支撐（不是線性、是動態循環）：

1. **工作環境**：辦公空間、文化、彈性
2. **待遇與培育**：薪資、發展機會、教育補助
3. **福利與獎勵**：彈性福利、員工旅遊、健康關懷
4. **友善職場**：DEI、心理安全、家庭友善
5. **財務獲利**：股票、分紅、員工持股（[[concepts/ESOP-employee-stock]]）

## 雇主品牌建置三步驟

1. **價值創造**：定義核心價值與承諾
2. **目前事蹟**：已實現的成果與證據
3. **未來規劃**：發展方向與承諾

→ 三步驟線性漸進，需反覆驗證與迭代。

## 常見陷阱

| 陷阱 | 後果 |
|---|---|
| **過度強調表達** | 與真實體驗落差 → 入職後失望 |
| **價值理想化** | 與目前事蹟脫節 → 信用破產 |
| **未來規劃空洞** | 員工看不到願景 → 留任率低 |
| **單一構面（如僅薪資）** | 薪資倒掛、其他構面崩塌 |

## 案例：[[entities/Tymphany]] 員工夢工廠

- **三部曲音樂連結**：音樂節、公司樂團、董事長圓打鼓夢
- **四部曲夢想實踐**：員工夢想 1 年內達成（公司挹注資源）
- **多元溝通管道**：流感疫苗補助、面談（招募 + 離職）、ICRT 廣播曝光
- **聲音測試室**：讓客戶表達「夢想的聲音」（產品端的雇主品牌延伸）

## 黃柏翔背景

- 跨產業：銀行 → 教育 → 音響科技
- 多重身份：人資長 + 跨文化訓練協會理事 + PMP
- 哲學：「**先不要想可不可能，先想怎麼做**」—— 專業極限玩家

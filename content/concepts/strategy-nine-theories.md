# 策略九說（吳思華 2000）

**吳思華 2000 年《策略九說：策略思考的本質》**整理出策略管理的 9 種不同視角 — 從西方策略理論的綜合 + 中文管理脈絡的補強。^[extracted]

唐瓔璋（[[references/strategy-management-course-2024-nycu|策略管理 2024 課程]] p.5）反覆引用，作為**台灣本土策略管理 master framework**。^[teacher-annotation]

## 9 個策略視角

| # | 策略說 | 核心問題 | 西方對應 |
|---|---|---|---|
| 1 | **價值說** | 怎麼為顧客創造價值？ | Porter Value Chain / Kotler 5C |
| 2 | **效率說** | 怎麼最低成本達成？ | Porter Cost Leadership / Experience Curve |
| 3 | **資源說** | 公司有哪些獨特資源？ | RBV (Barney 1991) / Penrose 1959 / [[concepts/VRIO-framework|VRIO]] |
| 4 | **結構說** | 產業 / 公司結構決定什麼？ | Porter Five Forces / I/O economics |
| 5 | **競局說** | 競爭者之間動態如何？ | Game theory / coopetition |
| 6 | **統治說** | 公司治理結構如何決定策略？ | Williamson TCE / Agency theory |
| 7 | **互賴說** | 公司與生態系如何互動？ | Contingency theory / Stakeholder theory |
| 8 | **風險說** | 不確定性如何處理？ | SWOT / Scenario planning |
| 9 | **生態說** | 公司如何在生態系演化？ | Ecosystem / [[concepts/dynamic-capabilities|Dynamic capabilities]] |

## 與西方策略框架的對接

吳思華 2000 的價值是 **把西方策略理論做中文整合 + 補充華人管理脈絡**：

### 接近 Mintzberg 10 schools of thought
Mintzberg 1998《Strategy Safari》整理西方策略 10 個學派：Design / Planning / Positioning / Entrepreneurial / Cognitive / Learning / Power / Cultural / Environmental / Configuration。

吳思華 9 說 vs Mintzberg 10 schools 對比：
- 結構 / 重點不完全對應
- 吳思華偏 problem-driven（從問題問策略），Mintzberg 偏 historical evolution（學派演化）
- 吳思華刻意保留**中文哲學底色**（如「**形而上者謂之道，形而下者謂之器**」配合「策略」與「戰術」區別）

### 對 Porter / Barney / Grant 的整合
- 價值 + 效率 + 結構 ≈ Porter 三角
- 資源 + 生態 ≈ Barney RBV + Teece Dynamic Capabilities
- 競局 ≈ Game theory
- 統治 + 互賴 ≈ Williamson TCE + 生態系
- 風險 ≈ Scenario planning

## 教師眉批應用（[[references/strategy-management-course-2024-nycu]] p.5）

唐瓔璋把策略九說與西方策略演進並置：

```
1950s budgeting
  → 1960-70s corporate planning
  → late 1970s-80s industry analysis (Porter)
  → 1990s competitive advantage (Porter + RBV)
  → 21st turbulence (hypercompetition / Red Queen / 雙元理論)
```

每一階段對應吳思華 9 說的不同面向。

教師同時引「**形而上者謂之道，形而下者謂之器**」 — **策略九說是「道」**，具體框架（5 Forces / VRIO / Generic Strategies）是「器」。

## 為什麼這個框架重要

### 1. 跨文化策略思考整合
- 西方策略理論偏向**單一框架** strong claim（Porter / Barney 各自主張）
- 吳思華主張**九種視角並用** — 策略選擇取決於問題類型 + 公司情境
- 對應教師主張 Strategy is Relativism

### 2. 補充 [[concepts/MAO-framework|毛治國 MAO]]
- MAO 是決策框架（leader 視角）
- 策略九說是策略框架（公司視角）
- 兩者並用是台灣本土完整策略思考工具組

### 3. 教學節奏
- 給中文背景學生**整合 anchor**
- 對應 [[synthesis/financial-ratio-epistemology-yi-jing|象數理]] / [[synthesis/wei-zheng-leadership-and-subsidiary-management|諫太宗十思疏]] / [[synthesis/yoffie-five-rules-vs-sun-tzu-five-fundamentals|孫子兵法五事]] 等其他古典中文管理思想對接系列

## 反例 / 邊界條件

- **是否 9 個就夠？** 為什麼不是 10 或 12？分類本身的 arbitrary 問題
- **9 說之間的 overlap**：「結構說」與「統治說」邊界？「互賴說」與「生態說」差異？^[ambiguous]
- **預測力 vs 描述力**：策略九說偏 descriptive（事後分類），不太能 prescriptive（事前指引）
- **與 [[concepts/tautology-in-management-theory|tautology critique]] 的關係**：策略九說是否也是 catch-all 框架（任何策略結果都可事後對到某一說）— 不可證偽？^[inferred]

## 吳思華 entity 簡介

- **學歷**：政大企管所博士
- **任教**：國立政治大學企業管理學系
- **行政**：政大 EMBA 創辦人 → 政大商學院院長 → **政大校長**（2010-2014）→ **教育部長**（2014/8 - 2016/05）
- **代表著作**：
  - 《策略九說：策略思考的本質》（2000，繁中策略管理經典）
  - 《自由社會的人才養成》（2018）
- **特色**：把西方策略管理思想中文化 + 整合 + 落地到華人企業案例

詳見 Wu-Szu-hua。

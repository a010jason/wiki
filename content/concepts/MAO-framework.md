# V = MAO / AMC Framework（毛治國）

**毛治國 2018《決斷》**提出的 leadership decision-making 雙框架。**V = MAO** 解釋「為什麼會做某個決定」，**AMC** 解釋「**為什麼會察覺到要做決定**」。^[extracted]

唐瓔璋（[[references/strategy-management-course-2024-nycu|策略管理 2024 課程]]）反覆引用，作為**台灣本土策略管理思想**的核心框架之一。^[teacher-annotation]

## V = MAO 框架

```
V (Value / 價值產生) = M (Motivation 動機) × A (Ability 能力) × O (Opportunity 機會)
```

**乘法關係**：任一為零，整體為零。

| 維度 | 內涵 | 失敗時的問題 |
|---|---|---|
| **M Motivation** | 想做（want to） | 沒動力 — 員工 disengaged / leader 沒願景 |
| **A Ability** | 能做（able to） | 沒能力 — 技能不足 / 資源不足 |
| **O Opportunity** | 可做（allowed to） | 沒機會 — 時機不對 / 環境不支持 |

## AMC 框架（決策前的察覺）

```
A (Awareness 察覺) → M (Motivation 動機) → C (Capability 能力)
```

時序流程：**先察覺問題或機會，才產生動機，才動用能力**。

如果 awareness 缺失 → 即使有動機 + 能力也用不上（[[concepts/icarus-paradox|icarus paradox]] 的 awareness 死角）。

## 兩框架的合用

| 階段 | 框架 | 問題 |
|---|---|---|
| 決策前察覺 | **AMC** | 為什麼看到 / 看不到問題？ |
| 決策落地 | **V = MAO** | 為什麼成功 / 失敗？ |

**完整鏈條**：Awareness → Motivation → Capability → Opportunity → Value

## 與西方框架的對比

### vs Ulrich HR Roles
- Ulrich 的 [[concepts/ulrich-hr-roles|4 角色框架]] 是組織能力建構視角
- MAO 是個人 / leader 決策視角
- 互補：HR 設計組織以提供 A + O；leader 自己負責 M

### vs Vroom Expectancy Theory
- Vroom [[concepts/expectancy-theory|VIE 模型]]：Motivation = E→P × P→O × V
- 表面類似（都有 motivation × ability × outcome）
- 差異：
  - VIE 是 micro 心理機制（一個員工為何努力）
  - MAO 是 macro 決策框架（一個 decision 為何 valuable）

### vs RBV (Resource-Based View)
- RBV 強調 capability（A）的 source
- MAO 把 capability 放在三維度之一
- MAO 不爭論 capability 是否 sustainable（[[concepts/tautology-in-management-theory|tautology critique]]），只看當下能否動用

### vs Christensen RPV Framework
- [[concepts/RPV-framework|RPV]]：Resources / Processes / Values
- MAO 的 Ability ≈ RPV Resources + Processes
- MAO 的 Motivation ≈ RPV Values（部分）
- MAO 缺 Process 維度，Christensen 框架更完整

## 跨案例應用（推測）^[inferred]

### [[entities/HTC]] pivot to VR 失敗
- **A (Awareness)**：HTC 確實察覺手機業崩塌（從 [[concepts/penguin-effect|企鵝效應]] 看是被迫察覺）
- **M (Motivation)**：強烈（生存）
- **C / A (Capability)**：弱 — VR ecosystem / ISV / Vision Pro 級設計缺乏
- **O (Opportunity)**：差 — Facebook Oculus / Sony PSVR 已先動
- **V**：低（仍是 niche player）

### [[entities/Lego-Group]] 2004 turnaround 成功
- **A**：危機明顯（瀕臨破產）
- **M**：強烈 — Knudstorp 36 歲外部 CEO 接手
- **C**：Knudstorp 顧問背景 + 願犧牲家族 legacy + AFOL 社群協作
- **O**：玩具產業 Star Wars / Harry Potter licensing 機會窗口
- **V**：高（brand value \$2B → \$7.5B）

### [[entities/Mobileye]] 2017 Intel 收購
- **A**：Intel 察覺 ADAS 機會 ✓
- **M**：強烈 — \$15.3B 收購是大注
- **C**：Intel 晶圓 + Mobileye AI 視覺
- **O**：自駕產業時機窗口
- **V**：成功 — 2022 spin off 釋放 valuation

- **MAO 是 framework 還是 tautology？** 「動機 × 能力 × 機會 = 價值」可能也是恆真句（按 [[concepts/tautology-in-management-theory|唐瓔璋 critique]] 標準）—— 三個因素中任一缺失自然沒結果，但**這個論述是否有預測力**？^[inferred]
- **與 Christensen [[concepts/RPV-framework|RPV]] 嚴格對比**：MAO 對 Process 維度的處理是否不足？^[inferred]
- **AMC 與 [[concepts/desktop-vs-platform-mindset|Desktop vs Platform Mindset]] 的關係**：incumbent 的 awareness 死角是 paradigm-locked 而非單純 lack of awareness ^[inferred]

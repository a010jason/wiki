# SHRM 三派觀點

## 一句話

Strategic HRM 不是一個框架，是**三個並存的觀點**，從不同角度回答「HR 系統怎麼幫公司賺錢」這個問題。

| 觀點 | 主問 | 核心邏輯 |
|---|---|---|
| **RBV** | HR 能不能變成 sustained competitive advantage? | HR 系統作為 inimitable 資源 |
| **Best Practice** | 有沒有 universal 的高績效 HR 做法？ | 有 8 項放諸四海皆準的實務 |
| **Contingency** | HR 怎麼跟外部環境 + 內部策略對齊？ | 沒有 best，只有 fit |

## 觀點 1：Resource-Based View（RBV）

把 Grant Ch5 RBV / VRIN 框架套到 HR 系統上：

| 條件 | HR 系統怎麼滿足 |
|---|---|
| **V**aluable | HR 實務直接提升 productivity / quality / customer service |
| **R**are | HR 系統獨特、競爭者沒有同類 |
| **I**nimitable | HR 政策深植組織文化、social complexity、path-dependent |
| **N**onsubstitutable | 沒有其他資源能取代 high-performance HR system |

^[extracted]

教師批註：「**長期賺錢？How？思考的是如何持續賺錢**」— 暗示 RBV 在 HR 上的應用，重點是把 HR 從「cost」框架移到「sustained competitive advantage」框架。^[inferred from instructor annotation]

**例子**：Fintech 銀行設立**獨立的 Fintech 人才升遷管道**（與傳統銀行員不同），用 HR 系統創造 inimitable 人才優勢。^[inferred from instructor annotation]

## 觀點 2：Best Practice（最佳實務 / High-Performance Work System）

Pfeffer (1998) 的高績效工作系統 8 大實務，可放諸四海皆準：

1. **雇用保障**（employment security）
2. **選擇性招募**（selective hiring）
3. **自我管理團隊**（self-managed teams）
4. **高薪績效激勵**（high pay contingent on performance）
5. **大量訓練**（extensive training）
6. **降低地位差距**（reduction of status differences）
7. **資訊分享**（sharing information）
8. **（隱含的）民主參與、長期承諾**

^[extracted]

**Best Practice 觀點的關鍵假設**：這 8 項是 universal 的 — 不管產業 / 國家 / 公司階段都該做。

教師批註指出限制：**雇用保障若缺失，員工的回報心理（reciprocity）會下降，無法投入心力**。^[inferred from instructor annotation] 這呼應 Pfeffer 的 **Rule of 1/8**（已在 hot.md takeaways）— 只有 12.5% 的公司真正拿到 best practice 的好處，因為大多數企業在某環節中斷。

## 觀點 3：Contingency（權變觀點）

最 popular 也最被現代 SHRM 教科書採用的觀點：**沒有 best，只有 fit**。

HRM 必須與三個維度同時對齊：

| 對齊維度 | 內容 |
|---|---|
| **外部一致性**（external consistency） | HR 與 PESTLE / Porter 5 forces / 產業生命週期搭配 |
| **內部一致性**（internal consistency） | HR 與企業策略（cost leader vs differentiator vs focus）搭配 |
| **HR 實務間一致性** | 招募 / 訓練 / 薪酬 / 績效四子系統互相 reinforce，不互相抵銷 |

^[extracted]

**內部一致性的四面向**（教師補充進一步細分）：

1. 實務間一致（招募 → 訓練 → 績效 → 薪酬，標準對齊）
2. 員工間一致（同職位、同績效應該給同樣對待）
3. 時間一致（policy 不能朝令夕改）
4. 言行一致（policy 寫的與 manager 執行的不能不同）

任一不一致 → 公平感知（fairness perception）下降 → 工作動機下降。^[inferred from instructor annotation]

**例子**：陽明海運成立 ESG 專責單位、董事會設風險管理委員會 — 是 **外部一致性**（回應 ESG 環境）+ **內部一致性**（強化誠信經營與 HRM 整合）的案例。^[inferred from instructor annotation]

## 三觀點不互斥的整合

現代 SHRM 主流（包括溫金豐 Ch3）**用 contingency 包覆 RBV + best practice**：

```
        Contingency
       ┌──────────┐
       │  ┌──────┐│
       │  │  RBV  ││  ← 從 RBV 找出哪些 HR 實務「值得做到 sustained advantage」
       │  └──────┘│
       │  ┌──────┐│
       │  │ Best ││  ← 從 best practice 找出基本盤
       │  │ Pract││
       │  └──────┘│
       └──────────┘
   ↑ 用 fit 判斷取捨
```

^[inferred]

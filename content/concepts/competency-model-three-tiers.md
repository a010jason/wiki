# 職能模型三層架構

## 一句話

職能模型 = 把「對的人」的標準拆成可教可選的維度。三層架構讓組織從 job-by-job 設計轉到 competency-by-competency 設計，便於跨職位橫向發展與接班計畫。

## 三層架構

| 層級 | 範圍 | 例子 |
|---|---|---|
| **Core Competencies**（核心職能） | 全員必備 | 誠信、客戶導向、學習力、團隊合作 |
| **Professional Competencies**（專業職能） | 職類專業 | 工程師的 coding、業務的 prospecting、醫師的 diagnosis |
| **Managerial Competencies**（管理職能） | 跨層級管理 | 領導力、決策、衝突管理、教練式對話 |

^[extracted]

三層之間是**累積**而非互斥 —— 工程主管同時需要 core + engineering professional + managerial 三套職能。

## 職能組成 = K + S + AOM

教師補充把每個職能拆成兩層：

```
Knowledge（知識）─┐
                 ├─ 可教（visible / trainable）
Skill（技能）────┘
─────────────────────
Self-concept（自我概念）─┐
Trait（特質）──────────├─ 難教（hidden / 偏選才）
Motive（動機）─────────┘
```

^[extracted]

這是 **Spencer & Spencer (1993)「冰山模型」** 的中文教學版（source 未明點 Spencer，但結構一致）。^[inferred]

**Implication**：

- **K + S** 可以靠訓練解決 → HR 該投資 training
- **AOM** 比較難改 → HR 該在選才階段就把關（[[concepts/employee-selection-tools]]）

## Job-based HR vs Competence-based HR

教師補充 p.1 直接點出兩個 HR 典範：

| 維度 | Job-based HRM | Competence-based HRM |
|---|---|---|
| **管控單位** | 職位（job） | 職能（competency） |
| **核心文件** | 工作說明書 + 工作規範 | 職能模型 + 行為錨定描述 |
| **選才標準** | 「能不能做這份工作？」 | 「具備哪些可移轉職能？」 |
| **訓練設計** | 為當前職位設計 | 為職能發展設計 |
| **薪酬基礎** | Job grade（職等） | Skill / competency pay |
| **適用組織** | 穩定、流程化、傳統製造業 | 變動、創新、知識型 |

^[extracted + inferred]

教師暗示**Competence-based 是 modern HRM 主流**，但 Job-based 在台灣製造業仍是大宗。^[inferred from instructor annotation]

## 與 Job Description / Specification 的關係

職能模型不取代工作說明書，是上層架構：

- **Job Description**（工作說明書）描述「這份工作做什麼」 — 任務、責任、工作內容
- **Job Specification**（工作規範表）描述「需要什麼條件做這份工作」 — 學歷、經驗、證照
- **Competency Model**（職能模型）描述「具備什麼能力的人能做這份工作 + 未來能做更多」 — 跨工作可移轉

^[extracted]

Specification 是 Competency Model 的**最低門檻**子集；Competency Model 是**潛能上限**的描述。^[inferred]

## 對接其他框架

- **vs [[concepts/core-competency]]** (Kotler / Prahalad-Hamel)：core-competency 是公司資源層；competency-model 是員工能力層。Wiki 已有 Kotler 三條件版的 core-competency，本概念是 HRM 版的 individual-level 對應
- **vs [[concepts/employee-selection-tools]]**：職能模型 = 選才標準；selection-tools = 量度方法
- **vs [[concepts/job-analysis]]**：job analysis 產出 job description + job specification + competency model 三者，是上游
- **vs [[concepts/big-five-personality]]** / [[concepts/emotional-intelligence]]：Big Five 與 EI 是 trait + motive 的特定子集，屬職能冰山下半部
- **vs [[concepts/job-characteristics-theory]]** (JCM)：JCM 描述工作對員工的影響；competency model 描述員工適配工作的標準 — 互補視角

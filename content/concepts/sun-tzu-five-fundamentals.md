# 孫子兵法五事（道天地將法）

《孫子兵法·始計篇》開篇所列**領導者必須先衡量的五個基本面**：「故經之以五事，校之以計，而索其情：一曰道，二曰天，三曰地，四曰將，五曰法」。^[extracted]

被教師（[[references/HBS-9-722-439-Musk-doubling-down-case|Musk Doubling Down lecture]]）用來對應 [[concepts/strategy-rules-yoffie-cusumano|Yoffie/Cusumano 5 rules]]，做東西方策略框架的 cross-domain benchmark。^[teacher-annotation]

## 五事原文與現代詮釋

### 道
> 「道者，令民與上同意也，可與之死，可與之生，而不畏危。」

- **意涵**：使民意與上同 — 領導者的願景、價值觀、共同目標
- **現代對應**：mission / vision / 組織文化 / 共同信念
- **教師對接**：Yoffie Rule 1「Look Forward, Reason Back」— 展望未來的方向 + 整合上下共識
- **註**：Games（佈局）/ Priority / set boundaries

### 天
> 「天者，陰陽、寒暑、時制也。」

- **意涵**：天時 — 季節、氣候、時間規律
- **現代對應**：產業週期 / 經濟環境 / 時機判讀 / paradigm shift
- **教師對接**（與「地」合一）：Yoffie Rule 2「Make Big Bets, Without Betting the Company」— Context（時機）+ Self-fulfilled prophesy（自我實現預言）

### 地
> 「地者，遠近、險易、廣狹、死生也。」

- **意涵**：地利 — 戰場位置、地形、距離、險要、生死之地
- **現代對應**：市場地理 / 競爭環境 / 進入策略 / Scope（事業範疇）
- **教師對接**：與「天」合 — Yoffie Rule 2 的 Scope 面

### 將
> 「將者，智、信、仁、勇、嚴也。」

- **意涵**：將領的 5 種特質（智謀、誠信、仁愛、勇敢、嚴明）
- **現代對應**：CEO / Leader 個人特質
- **教師對接**：Yoffie Rule 4「Exploit Leverage and Power—Play Judo and Sumo」— 勢（capability）

### 法
> 「法者，曲制、官道、主用也。」

- **意涵**：軍法、組織編制、官員任用、後勤管理
- **現代對應**：組織結構 / 制度 / 流程 / governance
- **教師對接**：Yoffie Rule 3「Build Platforms and Ecosystems」+ Rule 5「Personal Anchor Organization」— 法的兩個面（規則 + 組織設計）

## 教師中文眉批對接 Yoffie 5 rules

完整對應表（[[references/HBS-9-722-439-Musk-doubling-down-case|Musk lecture]] p.1）：

| Yoffie 法則 | 孫子五事 | 教師註 |
|---|---|---|
| 1. Look Forward, Reason Back | **道** | Games / Priority / set boundaries |
| 2. Make Big Bets, Without Betting the Company | **天地** | Context / Scope / Self-fulfilled prophesy |
| 3. Build Platforms and Ecosystems—Not Just Products | **法** | rules / BU vs platform / value chain / networks / corp-strategy |
| 4. Exploit Leverage and Power—Play Judo and Sumo | **勢**（接近「將」+「法」之間） | capability |
| 5. Shape the Organization around Your Personal Anchor | **法** | — |

⚠️ 對應**不完美**：
- 教師用「天地」對 Rule 2，但孫子原意「天時地利」更接近 Rule 1 的 framing
- 教師用「法」對 Rule 3 + Rule 5，「法」用兩次
- 「勢」（Rule 4）不在五事原文中，是孫子兵法後文〈勢篇〉概念
- 嚴格 1-to-1 mapping 不存在 ^[inferred]

## 跨案例應用（教師主要用法）

### [[entities/Elon-Musk]] — Musk Empire
教師核心問題：Musk 7 公司是否符合五事？
- **道**：火星殖民 vision 有；但 7 公司願景不一致 — 「**沒有 synergy**」
- **天地**：Gigafactory bet 進 commodity 是否符合時機？教師標「**活取熊膽**」（Cybertruck）暗示時機過早
- **將**：Musk 個人特質充足，但「智、信、仁、勇、嚴」中**信**（誠信 — funding secured tweet）+**仁**（員工待遇）有爭議
- **法**：缺乏 platform thinking，**Empire 結構違反「法」的整合**

### [[entities/Steve-Jobs]] / [[entities/Apple]]
- **道**：「Think Different」「Change the world through technology」
- **天地**：1997 回歸 Apple 是 punctuated equilibrium 的 timing
- **將**：Jobs 個人「智 + 嚴」突出，「仁」不足（Nano Manager）
- **法**：Digital Hub + App Store + iOS = 平台 + 生態系

### [[entities/Samsung-Electronics]] — Yun Jong Yong
- **道**：Lee Kun-hee 1993 Frankfurt 宣言
- **天地**：1997 亞洲金融風暴是「危機=機會」
- **將**：Yun sashimi theory「天下武功唯快不破」
- **法**：垂直整合 + GMO 全球統一行銷

### [[entities/Lego-Group]] — Knudstorp
- **道**：「Learning-through-Play」brand framework 七層
- **天地**：2004 危機是 turnaround 時機
- **將**：Knudstorp 36 歲新人 + 顧問背景
- **法**：re-position → re-configuration → mobility barrier → value chain reinvention

## 為什麼這個框架重要

1. **歷史耐久性**：2,500 年前的框架仍能套用現代 CEO 戰略 — 反映**領導 / 策略本質的不變性**
2. **跨文化共鳴**：與西方框架（Yoffie / Porter / RBV）並列討論時，給中文背景的學員**熟悉的 anchor**
3. **教學節奏**：5 事比 Porter 5 forces 更接近 leader 視角（領導者該想什麼），對應 [[skills/CEO-decision-making|CEO decision making]]
4. **批判功能**：用古典框架評現代 CEO（Musk 違反「道」「法」），有「歷史警示」的修辭力 ^[inferred]

## 反例 / 邊界條件

- **不適合戰術層級**：五事是 grand strategy 層級，對 product launch / pricing 等戰術不適用
- **「將」5 特質（智信仁勇嚴）的 weighting 未定**：現代 CEO 是否仍需「仁」？貨幣化年代「智 + 嚴」可能更主導
- **「道」與企業願景的差異**：孫子「道」是君民同心，現代企業有股東 / 員工 / 客戶三方，「道」對 primary customer 不清晰
- **歷史包袱**：對非中文背景學員，五事看似「東方神秘主義」 — 可能反而妨礙嚴肅討論 ^[inferred]

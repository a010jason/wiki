# Business Buying Process

## What It Is

Kotler 16e Ch04 的 B2B 採購八階段流程（Figure 4.1）：^[extracted Ch04 p.11]

```
1. Problem recognition
2. Need description
3. Product specification
4. Supplier search
5. Proposal solicitation
6. Supplier selection
7. Contract negotiation
8. Performance review
```

比 [[concepts/buying-decision-process-consumer]] 的 5 階段多三階段（Need description / Product specification / Proposal solicitation），反映 B2B 採購的正式化、文件化、責任分散特性。

## 八階段細節

### 1. Problem Recognition

由 internal stimuli（設備老舊、員工反映、KPI 缺口）或 external stimuli（業務員推銷、展覽、競品壓力）觸發。

對應 [[concepts/buying-center]] 角色：**Initiator + User**。

### 2. Need Description

把模糊問題（「PACS 太慢」）轉成具體需求（「需要 sub-second loading」）。

對應角色：**User + Influencer**（IT 工程師、外部顧問）。

### 3. Product Specification

寫出 RFP 規格書。

**Product Value Analysis（PVA）** = 成本縮減手法，研究零組件能否重新設計、標準化、用更便宜方法生產，而不損害產品性能。^[extracted Ch04 p.13]

對應角色：**Influencer + User**。

### 4. Supplier Search

五大管道：^[extracted Ch04 p.14-15]

- Catalog sites
- Vertical markets（垂直 hub，按產業）
- Pure Play auctions（純拍賣平台）
- Private exchanges（私有交易所）
- Spot / barter markets

兩類 hub：
- **Vertical hubs** — 按產業（醫材、化工、機械）
- **Functional hubs** — 按職能（採購、物流、HR）

範例：Ritchie Bros. Auctioneers（工程機械拍賣）= vertical hub + auction 混合。

### 5. Proposal Solicitation

RFP 發出，請 suppliers 提案。

### 6. Supplier Selection

四維評估：^[extracted Ch04 p.17]

| 維度 | 中文 |
|---|---|
| **Price** | 價格 |
| **Reputation** | 商譽 |
| **Reliability** | 可靠度 |
| **Agility** | 敏捷度（快速回應變更的能力） |

對應角色：**Decider + Approver**。

### 7. Contract Negotiation

合約類型：^[extracted Ch04 p.19]

- **Blanket contracts**（總括合約）— 含 stockless purchase plans（無庫存採購方案）
- **Periodic purchase orders** — 定期下單
- **Long-term contracts** — 長期固定
- **Vendor-Managed Inventory (VMI)** — 由供應商管理客戶庫存

VMI 是高度信任 / 整合的供應關係，常見於汽車業、零售業。

### 8. Performance Review

採購後評估，影響 future supplier selection。

對應角色：**User + Decider**。

## 進階：Online Buying & Online Hubs

當代 B2B 採購大量數位化：^[extracted Ch04 p.15]

- 公司用 vertical / functional hubs 取代傳統業務員拜訪
- Catalog sites 取代紙本目錄
- Auction 平台讓買賣雙方公開競標

意涵：B2B 行銷的 [[concepts/7Ts-marketing-tactics]] Distribution 戰術從「業務拜訪」轉向「平台 presence」。

## Effective Business Marketing Programs 四要素

Kotler 對 B2B 行銷者的四個指導：^[extracted Ch04 p.21]

1. **Systems selling** — 從 product seller 升級到 solution provider
2. **Additional services** — 在產品上 add 高品質服務
3. **Customer reference programs** — 既有客戶推薦
4. **Online & offline communications & branding** — 多通道整合

## Source 反例 / 質疑

- **8 階段是規範性模型** — 現實 B2B 採購可能高度跳階 / 迭代（SaaS、product-led growth 時代）。^[inferred — 隱含批評]
- **「Fewer, larger buyers」假設** 在當代長尾 / SaaS self-serve 模式下不一定成立。^[inferred]
- **8 階段是否適用 institutional / government markets**：Kotler 用一頁帶過 institutional 與政府市場，沒處理採購法規、招標流程、生命週期差異。^[ambiguous]
- **SaaS / PLG 場景下 8 階段可能壓縮到 1 階段** — End user 直接付費試用，整個流程被個人化決策取代。^[inferred — 隱含批評]

## Jason 觀察：醫院採購 EBM PACS / AI 的 8 階段映射

EBM 銷售流程的階段對應：^[inferred — Jason 個人延伸 / visibility-consideration: internal candidate]

| 階段 | 醫院內動作 | EBM 應對 |
|---|---|---|
| 1. Problem recognition | 放射科主任反映 workflow 痛點 | KOL 學會 session，種需求 |
| 2. Need description | 列規格（throughput / accuracy / integration） | 提供需求 template |
| 3. Product specification | 寫 RFP | 主動參與規格制定 |
| 4. Supplier search | 詢價國際大廠 + 本地廠商 | 確保被列入 vendor list |
| 5. Proposal solicitation | 收 3-5 家 proposal | 提供 ROI 試算 + 案例白皮書 |
| 6. Supplier selection | 評選會議 | 動員 Influencer（學會 KOL）+ User demo |
| 7. Contract negotiation | 採購室議價 | 提供彈性方案（per-study / 年度 / 長約） |
| 8. Performance review | 半年 / 年度檢視 | 主動提供 dashboard + improvement plan |

關鍵：**EBM 在階段 1-3 介入越早，後面 4-6 越好打**。直接進入階段 5-6 的 cold proposal 通常輸給「從 problem recognition 就在場」的對手。

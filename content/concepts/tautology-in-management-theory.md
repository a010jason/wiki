# Tautology in Management Theory

**唐瓔璋 SMJ 2010 論戰核心攻擊**（[[references/fighting-with-porter-lecture|Fighting with Porter lecture]]）— 主張 Porter / Barney / Blue Ocean 等策略管理大師命題**本質上是同義反覆**（tautology），按 Popper falsifiability 標準**不算 science**。^[teacher-annotation]

> 教師原話：「**Survival of the fittest（適者生存）**」「**widow of the late Mr. Smith（已故史密斯先生的遺孀）**」 — 同義反覆 = 不可被事實否證 = 沒有解釋能力。^[teacher-annotation]

## 什麼是 Tautology

### 邏輯定義
- 同義反覆 = 定義上必為真的命題（必然真）
- 例：`C(A+B) = CA + CB`（分配律恆真）
- 例：「未婚男性是 bachelor」（同義詞循環）

### Popper 標準
按 Popper falsifiability，**科學命題必須可被觀察否證**。Tautology 因為定義上必真，**永遠不能被任何事實否證** → 不算科學命題 → 沒有解釋力。

## Porter 1985 的 Tautology（教師 slide 7 攻擊主軸）

唐教授把 Porter 形式化為三段論：

| 階段 | 內容 |
|---|---|
| **大前提** | 「持續的競爭優勢」造就企業「高於行業水準的績效表現」 |
| **小前提** | 「差異化戰略」能創造和保持「競爭優勢」 |
| **結論** | 「差異化戰略」能造就企業「高於行業水準的績效表現」 |

教師批判（slide 7 藍底框）：「**但是，在中國，差異化不一定能造就企業高於行業水準的績效表現**」 — 直接舉反例否證小前提。^[teacher-annotation]

**大前提本身的問題**：「持續優勢 → 高績效」是定義上的循環 — **若一個優勢「不能持續」按定義就不算優勢，這是恆真句**。

## Barney 1991 VRIN 也是 Tautology（教師 slide 8 標紅箭頭）

教師連 [[concepts/VRIO-framework|Barney RBV]] 一起批：

> 「**VRIN (valuable, rare, inimitable, and non-substitutable) advantages are sources of sustainable competitive advantage**」 — 是恆真句

教師論證：**定義上稀有且不可模仿的優勢**當然會造成持續優勢，這是同義反覆無預測力。**RBV 不是 Porter 學派的反對立場，是同一類錯誤的姐妹版本**。^[teacher-annotation]

## 恆真句清單（教師 slide 9 批判對象）

教師把以下管理理論並列為**同類恆真句**：

| 框架 | 為何被批為 tautology |
|---|---|
| **Porter 1985 Generic Strategies** | 差異化 → 競爭優勢 是循環定義 |
| **Barney 1991 VRIN / RBV** | 不可模仿優勢 → 持續優勢 是定義循環 |
| **Core Competency** (Prahalad-Hamel) | 核心能力 → 競爭優勢 |
| **Disruptive Innovation** (Christensen) | 顛覆者 → 成功取代 incumbent |
| **Organizational DNA** (Toyota vs Nissan) | 強 DNA → 強企業 |
| **Blue Ocean Strategy** | 未爭奪市場 → 成功 |
| **SWOT** | 內部優勢 → 成功；外部威脅 → 風險 |

教師戲謔對照（slide 9）：兩本台灣選舉口號書「**明天會更好(1997)**」「**馬上就好(2008)**」 — 暗指**管理理論恆真句 = 政治競選口號**：聽起來對，但不可證偽。^[teacher-annotation]

## 暢銷書與偽科學（教師 slide 10）

教師最尖銳的諷刺：把管理暢銷書與保健偽科學並列：

- **管理暢銷書**：《追求卓越》《基業長青》《成功不墜》
- **保健偽科學**：「池守湧泉能量足墊」+ 腳底反射圖

教師立場：「**策略管理若不能 Popper-falsifiable 就不是 science**」 — 兩類書同樣是**事後解釋成功者**的倖存者偏差。^[teacher-annotation]

## 為什麼這個批判重要

### 1. 科學哲學基礎
- 區分 hypothesis（可證偽）vs assertion（恆真）vs definition（純語意）
- 對應 [[concepts/falsifiability-popper|Popper 1934]] 的核心 demarcation 原則

### 2. 對策略研究方法論的衝擊
- 唐教授提出替代方案：**Bayesian Inference**（"Does Firm Performance Reveal its Own Causes? Role of Bayesian Inference"，SMJ 2010）
- 從歸納案例堆 → 統計推論 + 多 sample replication
- 對應 [[synthesis/sampling-choice-shapes-results|Short, Ketchen, Palmer 2002 JoM]]：同 hypothesis 不同 sample 得不同結果

### 3. 對 MBA 教學的反省
- 用 Porter / Barney 框架做 strategic analysis 像在做**事後合理化**
- 應該怎麼教？教師立場：**用 case 但同時教 falsifiability 與 Bayesian 思維**

### 4. 對 PM 工作的啟示（Jason 視角）^[inferred]
- 當提案用「我們有 core competency」「我們做 differentiation」框架時 — **要警覺這可能只是事後語言裝飾**
- 真正可驗證的 hypothesis：「如果我們做 X，我們會在 Y 時間達到 Z 指標」
- 對應 [[concepts/ab-testing-as-strategy|A/B testing]] / [[concepts/hypothesis-driven-product]]

## 反例 / Tautology 的辯護

### 反論 1：Tautology 仍可有 heuristic value
- 「適者生存」雖然是同義反覆，但**提示研究者注意適配**
- 「核心能力」雖無預測力，但**幫助管理者整理思路**
- 教師反駁（slide 10）：但這是 heuristic 不是 science；不該以科學自居

### 反論 2：操作化定義可救
- 把 「持續優勢」定義為「ROE &gt; 行業平均連續 N 年」 → 變成可測 hypothesis
- 教師立場（推測）：操作化是對的方向，但 Porter / Barney 自己沒做 — 是後人在補洞 ^[inferred]

### 反論 3：Bayesian 也不是萬靈丹
- 唐教授提的 Bayesian inference 也需要 prior 假設、樣本選擇 — 不是無偏 ^[inferred]
- 對應 [[synthesis/sampling-choice-shapes-results|sample 選擇也塑造結論]]

### 反論 4：中國反例可能不是普世
- 教師用「中國差異化不一定贏」否證 Porter — 但中國市場特殊性（[[concepts/institutional-voids|institutional voids]] / 「盜亦無道」）是否能 generalize 反過來否定 Porter 在美國市場的有效性？^[inferred]
- 這個反例本身的 boundary 也需 challenge

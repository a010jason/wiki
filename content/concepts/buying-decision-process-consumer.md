# Consumer Buying Decision Process

## What It Is

Kotler 16e Ch03 提出的消費者購買流程五階段（Figure 3.3）：^[extracted Ch03 p.22-23]

```
Problem recognition
       ↓
Information search
       ↓
Evaluation of alternatives
       ↓
Purchase decision
       ↓
Postpurchase behavior
```

Kotler 自承「The consumer **typically** passes through five stages」— **typically** 一字暗示非絕對，衝動購買 / 習慣性購買可能跳階。^[extracted]

## 五階段細節

### Stage 1 — Problem Recognition

需求由 **internal stimuli**（飢餓、無聊、社交焦慮）或 **external stimuli**（廣告、朋友推薦、社交媒體曝光）觸發。

行銷者的工作：辨識什麼 trigger 把潛在需求變成顯性問題。

### Stage 2 — Information Search

四種資訊來源：^[extracted Ch03 p.25]

| 來源 | 例 |
|---|---|
| **Personal** | 家人、朋友、同事 |
| **Commercial** | 廣告、銷售員、官網、包裝 |
| **Public** | 媒體報導、消費者組織、評鑑 |
| **Experiential** | 試用、檢視、操作體驗 |

行銷者目標：在客戶會搜尋的四個來源裡都被找到。

### Stage 3 — Evaluation of Alternatives

三個機制：^[extracted Ch03 p.27-28]

- **Beliefs and attitudes** — 對品牌的既有信念
- **Information processing** — 認知資源的有限性
- **[[concepts/expectancy-value-model]]** — Σ(Belief × Evaluation) 加權加總

詳細展開：

- **A = ΣBiEi** — Attribute i 上的 belief × evaluation 加總，產生對 brand 的總體偏好分數
- 範例（Table 3.1 Laptop 選擇）：A/B/C/D 四台 laptop 在 Memory / Graphics / Size / Price 四維 attribute 上各打 0-10 分，加總算 preference

### [[concepts/successive-sets]]（Figure 3.4）

評估階段中的 funnel 機制：

```
Total Set → Awareness Set → Consideration Set → Choice Set → Choice
```

範例（手機）：Apple / Samsung / Google / LG / HTC / Huawei / OnePlus（Total 7 個）→ 去掉沒聽過的 → 去掉不在意的 → 進入認真比較的 3-4 個 → 最終買 1 個。

意涵：行銷者要先讓品牌進 Awareness Set，再進 Consideration Set。POP（[[concepts/points-of-difference-and-parity]]）負責進入 awareness / consideration，POD 負責贏在 choice。

### Stage 4 — Purchase Decision

從「意圖」到「實際買」中間有 intervening factors（Figure 3.5）：^[extracted Ch03 p.30-31]

- **Situational factors** — 缺貨、突發財務狀況、地理可得性
- **Opinions of others** — 配偶反對、銷售員態度

**Decision heuristics** — rules of thumb（非 compensatory）：

- Lexicographic — 按重要性逐欄篩選
- Conjunctive — 所有屬性都要過門檻
- Elimination-by-aspects — 依優先順序排除不合格者

**Elaboration Likelihood Model (ELM)** — central route（深思熟慮）vs peripheral route（外圍線索如 celebrity endorsement、品牌名）。^[extracted but not expanded]

### Stage 5 — Postpurchase Behavior

三個關注點：^[extracted Ch03 p.32]

- **Postpurchase satisfaction** — 期望 vs 實際的 gap
- **Postpurchase actions** — 重購 / 棄用 / 推薦 / 申訴
- **Postpurchase uses and disposal** — 怎麼用、怎麼處置（呼應 [[concepts/customer-value-proposition]] 的 disposing cost）

**Cognitive dissonance** — 買完後懷疑「我是不是買錯了？」行銷者透過 owner manual / thank-you email / community 平台化解。

## [[concepts/perceived-risk]] 六類

Intervening factor 細分為六類 risk（Ch03 p.33）：

- Functional / Physical / Time / Financial / Psychological / Social risk

不同產品類別的主要 risk 不同：
- 醫療：Physical + Functional risk 主導
- 奢侈品：Social + Psychological risk 主導
- 投資：Financial + Time risk 主導

## EKB Model 的關係

Kotler 5-stage 是 **Engel-Kollat-Blackwell (EKB) 1968** 的簡化版：^[extracted Ch03 p.21]

EKB 結構：
```
Input (Stimuli)
  ↓
Information Processing (Exposure / Attention / Comprehension / Acceptance / Retention)
  ↓
Decision Process (Problem Recognition / Search / Alternative Evaluation / Choice / Purchase / Outcomes)
  ↓
Decisional Variables (Beliefs / Motives / Attitudes / Lifestyle / Intentions)
  ↓
External Factors (Cultural Norms / Social Class / Reference Group / Family / Unexpected Circumstances)
```

Kotler 把 EKB 的 Information Processing 子階段折進「Information search」+ 「Evaluation」，並把 Decisional Variables 移到 Consumer Psychology 章節。^[inferred]

## Source 反例 / 質疑

- **5 階段線性模型的反例** — Kotler 自己用 "typically" 暗示非絕對；衝動購買、習慣性購買、impulse buying 不走完整 5 階段。^[extracted]
- **Expectancy-value 假設 compensatory** — 但實務多用 non-compensatory heuristics；source 點到 heuristics 但未明說這構成對 expectancy-value 的反例。^[inferred — 隱含批評]
- **Successive sets 在數位時代是否還線性** — TikTok / Instagram 演算法推送使「awareness → consideration」可能單一 swipe 完成。^[inferred — 隱含批評]

## Jason 觀察：醫療 AI 客戶決策的不同

醫療 AI 客戶決策**不適用 5-stage 線性模型**：^[inferred — Jason 個人延伸]

- 醫療 AI 採購是 B2B → [[concepts/business-buying-process]] 8 階段更合適
- Successive sets 範疇較小（國際大廠 + 本地廠商 + 院內自建），通常 Total Set ≈ Awareness Set
- Evaluation 的 expectancy-value 加權標準在不同 stakeholder（醫師 / IT / 院長）權重不同 → buying center 內部需要 sub-evaluation
- Postpurchase behavior 在 SaaS / 訂閱模式下成為核心戰場（renewals / expansion）

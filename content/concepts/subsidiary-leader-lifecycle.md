# Subsidiary Leader Lifecycle

Christopher Bartlett 在 [[references/HBS-levendary-cafe-case|Levendary Café case]] 中明引的子公司領導人三階段演化框架。每階段任務、HQ 支援方式、典型危機都不同；**演化是雙向的**（可前進也可退化）。^[extracted]

> Levendary case mentor 在第三次會議前教 Foster：「Chen 現在是 [[entities/Louis-Chen|Local Baron]]，問題是他能不能演化成 Professional Manager — 或必須換人」。^[extracted]

## 三階段

### 1. Go-Getter（拼命三郎 / 自走砲）

**特徵**：
- 剛上任 founding manager / 首任 subsidiary head
- 主要任務 = **建立 beachhead**：第一家店、第一個客戶、第一筆訂單
- 高自主性、高 entrepreneurial energy
- HQ 提供 resources + 信任授權
- 典型誤判：高層認為「給人 + 給錢 + 給時間就會自然演化」

**Levendary 對應**：Chen 2009/9-2010/6（前 9 個月開頭幾家店、上海浦東 + 北京大使館 = 高檔白領客群，最接近 Levendary 美國概念）

### 2. Local Baron（藩鎮割據 / 土皇帝）

**特徵**：
- 已建成 subsidiary 規模，**累積 local knowledge + local relationships**
- 開始**用在地化為由抵抗 HQ 標準**
- 主要任務漂移：從「建立 beachhead」變「保衛領地」
- 典型衝突：
  - 拒交 HQ 標準財務報表（Chen 拒 GAAP）
  - 偏離 product / concept（Chen 第 23 店改賣水餃）
  - 不接 HQ 高層巡視（Chen 從未接 Leclerc / White 來訪）
  - 高自主性變高 opacity
- HQ 處置選項（教師眉批）：「**收回成命、懲罰、感招...？**」
- 典型誤判：HQ 想用財務報表切入做 governance（教師眉批：「**很多帳不能記... 變成用財務管組織變革**」）

**Levendary 對應**：Chen 2010/6-2011/5 — 23 家店全偏離概念、拒月報、White 一年沒去中國

### 3. Professional Manager（太平盛世）

**特徵**：
- **平衡 local autonomy 與 global consistency**
- 主動把 local insights 反饋給 HQ（讓 HQ 變學習中心而非控制中心）
- 接受 [[concepts/transnational-strategy|transnational]] 整合網路角色：本地是 contributor + integrator
- 不再純粹是 boss，而是 connector
- HQ 給的不是 control 也不是 resources，而是 platform + global mandate

**Levendary 對應**：Foster 在第三次會議前思考的問題 — **Chen 能不能演化成這個階段？**（案例 cliffhanger，留白）

## 教師中文比喻 sequence（5 階段擴充版）

slide p.7 上：「**自走砲 → 野蠻成長 → 藩鎮割據 → 功高震主 → 太平盛世**」 ^[teacher-annotation]

教師把 Bartlett 三階段擴充為五階段中文比喻（mapping 推測）：

| 教師中文 | Bartlett 對應 | 補充 |
|---|---|---|
| 自走砲 | Go-Getter 早期 | 任意開火、單兵作戰 |
| 野蠻成長 | Go-Getter 晚期 | 速度優於品質 |
| 藩鎮割據 | Local Baron 早期 | 諸侯坐大、HQ 影響力下降 |
| 功高震主 | Local Baron 晚期 | 績效好但威脅 HQ 主導權 |
| 太平盛世 | Professional Manager | 整合進跨國網路 |

「功高震主」是教師額外的**中段警告**：Local Baron 越成功，HQ 與 subsidiary 的權力張力越大 — Chen 23 店在 1 年內就是「功高」但 cliffhanger 是「震主」階段。^[teacher-annotation]

## 與 Mintzberg / Bartlett-Ghoshal 框架的關係

- 配 [[concepts/integration-responsiveness-framework]]：subsidiary 隨 lifecycle 在 I-R 矩陣中移位（Local Baron 偏 Responsiveness 端、Professional Manager 中庸）
- 配 Mintzberg [[concepts/intended-vs-emergent-strategy]]：Local Baron 階段 emergent strategy 主導，Professional Manager 階段 intended + emergent 整合
- 配 [[concepts/global-entry-sequence]]（教師眉批暗示，連 Uppsala model）

## 反例 / 邊界條件

- **不必然單向**：Professional Manager 可能因為績效壓力退化回 Local Baron（保衛領地心態）；Go-Getter 也可能因為失敗或挫折提早 burnout
- **HQ 角色 mirror image**：每階段都需要 HQ 對應行為（Go-Getter 配 resources + 信任、Local Baron 配 boundary-setting、Professional Manager 配 platform） — HQ 不演化 subsidiary 也卡住
- **教師眉批**：「**為何 HQ 與 subsidiary 一年沒互動 = governance 失敗**」 — Bartlett 三階段預設 HQ 是 active partner，**case 的 White「自從一年前 Howard 主持浦東分店的開幕典禮以來，就沒有高階主管拜訪中國」是嚴重 deviation** ^[teacher-annotation]
- **與「諫太宗十思疏」的跨領域類比**：[[synthesis/wei-zheng-leadership-and-subsidiary-management]] — 古代「載舟覆舟」「鳴琴垂拱」對應 HQ-subsidiary 治理三階段

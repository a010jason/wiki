# Brand Value Chain

## What It Is

Kevin Lane Keller 提出、Kotler 16e Ch10 採用的**品牌價值傳遞模型**：^[extracted Ch10 Figure 10.2 p.21]

```
Marketing       ─→  Customer    ─→  Brand        ─→  Shareholder
Program           Mindset            Performance       Value
Investment

  × Program          × Marketplace    × Investor
    Multiplier         Multiplier       Sentiment
```

四階段 + 三個 multiplier。Multiplier 解釋「為什麼同樣的 marketing 投資在不同情境下產出不同結果」。

## 四個階段

### 1. Marketing Program Investment

公司投入到行銷的所有資源：廣告、產品 R&D、員工訓練、通路、活動、PR。

### 2. Customer Mindset

客戶端形成的**心智資產**：^[inferred Ch10 — CBBE]
- Awareness
- Associations
- Attitudes
- Attachment
- Activity

這層對應 [[concepts/brand-equity]] 的 customer-based brand equity (CBBE)。

### 3. Brand Performance

市場 / 競爭層面的 brand performance：^[inferred Ch10]
- 市場份額
- 價格溢價
- 客戶留存率
- 通路掌控力
- 競爭者反應

### 4. Shareholder Value

最終財務指標：股價、市值、股東報酬。對應 [[concepts/brand-equity]] 的財務 valuation。

## 三個 Multiplier（情境放大器）

Multiplier 是**情境變數**，決定上一階段能否順利轉化到下一階段：^[extracted Ch10 p.21 + 隱含 Keller]

| Multiplier | 位置 | 意義 |
|---|---|---|
| **Program Multiplier** | 投資 → 客戶心態 | 行銷計畫品質：clarity、relevance、consistency |
| **Marketplace Multiplier** | 客戶心態 → 市場績效 | 通路反應、競爭強度、客戶反應度 |
| **Investor Sentiment Multiplier** | 市場績效 → 股東價值 | 投資人對 brand 的解讀（巴菲特 vs 散戶） |

意涵：**同樣的行銷投資**，在不同公司產生不同效益，常常不是行銷本身好壞，而是 multiplier 的差異。

## 為什麼這個模型重要

董事會問「**行銷支出有沒有 ROI？**」時，BVC 提供答案框架：^[inferred — 業界應用]

- 不能只看「廣告 → 銷售」的 1 對 1 直接 ROI
- 要看完整鏈條：廣告 → 心智 → 市場 → 股價
- Multiplier 失靈時（如競爭者突襲 marketplace），同樣的廣告效果會被吃掉
- 行銷支出的長期效果在「客戶心態」階段累積，可能滯後 2-3 年才反映到股價

教師批註：「**如何打造強勢的品牌？**」— 提示 BVC 是「打造強 brand」的因果地圖。^[inferred from instructor annotation Ch10 p.21]

## Brand Audit + Tracking 對應到 BVC

| BVC 階段 | 量測工具 |
|---|---|
| Marketing Investment | 行銷預算、媒體支出 |
| Customer Mindset | [[concepts/brand-equity]] CBBE audit + tracking |
| Brand Performance | 市場份額、價格 premium、NPS |
| Shareholder Value | 股價、市值、Interbrand ranking |

意涵：BVC 給的不是單一指標，是**多層儀表板** — 結合 [[concepts/marketing-dashboard]] 的四 pathway。

## Source 反例 / 質疑

- **Multiplier 怎麼量？** Program multiplier 的「品質」、Marketplace multiplier 的「強度」都不易量化。^[ambiguous]
- **滯後問題**：股價反映 brand 的時間延遲，難以歸因。^[inferred]
- **B2B 品牌的 BVC 變形**：B2B brand 的 customer mindset 不是消費者個人感受，是組織採購決策；BVC 結構需要調整。^[inferred]
- **數位通路的即時測量打破 BVC 假設**：digital marketing 可以從 click → purchase 端到端追蹤，BVC 的「長鏈條」是否還必要？^[inferred — Jason 質疑]

## Jason 觀察：醫療 AI BVC 的特殊性

醫療 AI 的 BVC 鏈條比一般 B2C 多兩層：^[inferred — Jason 個人延伸]

```
Marketing  ─→  Clinician  ─→  Hospital   ─→  Insurance/   ─→  Shareholder
Investment     Mindset        Performance     Regulation        Value
                              (deployment)    Acceptance
```

醫療 AI 多了：
- **臨床採用率**（clinician adoption rate）— 醫師端的心智轉換不只是 awareness，是 trust + workflow embed
- **保險 / 監管 acceptance**：能否被列入給付（reimbursement）、FDA / TFDA / NMPA 核准

Multiplier 在醫療場景也變形：
- **Program multiplier** = 臨床研究品質（IRB-approved RCT vs anecdotal data）
- **Marketplace multiplier** = KOL 推薦、學會背書、PACS 廠商整合度
- **Investor sentiment** = 大型 deal 簽訂、IPO 預期

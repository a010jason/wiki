# Parenting Matrix（Goold-Campbell 母公司增值矩陣）

Michael Goold &amp; Andrew Campbell 1995-2000 提出的 **multibusiness corporate strategy** 經典工具。判斷母公司對子公司「**有沒有增值能力**」+「**有沒有增值機會**」的 2×2 matrix。^[extracted]

學術源頭：
- Goold, M., Campbell, A., &amp; Alexander, M. (1994). *Corporate-Level Strategy*. Wiley.
- Goold &amp; Campbell (1998). "Desperately Seeking Synergy". HBR.

唐瓔璋（[[references/strategy-management-course-2024-nycu|策略管理課 2024/06/04 課堂]]）用此框架分析 **Intel × Mobileye** 母合錯位 — Mobileye 收購是 ALIEN TERRITORY / VALUE TRAP 區。^[teacher-annotation]

## 2×2 矩陣結構

兩個維度：
- **X 軸**：母公司增值能力與子公司 critical success factors 的 fit（**Feel right** ↔ Misfit）
- **Y 軸**：母公司增值機會與子公司 needs 的 fit（**Benefit** ↔ Misfit）

四個象限：

| 象限 | 位置 | 母合判斷 |
|---|---|---|
| **HEARTLAND** | Feel right + Benefit | ✅ **核心事業** — 母公司既懂又能幫，深耕 |
| **EDGE OF HEARTLAND** | Feel right + 部分 Benefit | 邊緣核心 — 可發展但需注意 |
| **BALLAST** | Feel right + 無 Benefit | 壓艙石 — 賺錢但母公司沒幫，建議出售 |
| **VALUE TRAP** | Misfit + Benefit | ❌ **陷阱** — 子公司需要幫但母公司不會 |
| **ALIEN TERRITORY** | Misfit + 無 Benefit | ❌ **異地** — 完全不該擁有，立即剝離 |

## Intel × Mobileye 案例（教師應用）

教師判斷：Mobileye 收購對 Intel 是 **ALIEN TERRITORY + VALUE TRAP** 混合：

| 維度 | Intel-Mobileye 評估 |
|---|---|
| 母公司增值能力 fit | **Misfit** — Intel 是 PC/server CPU 文化、commodity-driven、規模製造；Mobileye 是 AI 視覺 / 汽車產業 / 軟體+服務 |
| 母公司增值機會 fit | **部分 Benefit**（晶圓製造）+ **部分 Misfit**（自駕需要長 sales cycle、汽車 OEM 關係、地圖資料、AI/SDS 開發） |
| 結論 | 「**Mobileye + Intel 不是母合優勢**」 |

教師眉批（[[references/strategy-management-course-2024-nycu|2024/06/04 課堂]] 板書）：紅箭頭直接點在 **ALIEN TERRITORY** 與 **VALUE TRAP** 兩象限，明確指 Intel 收購 Mobileye 是母合錯位。^[teacher-annotation]

### Intel 的應對策略（事後驗證）

事實時序：
- 2017 Intel 收 Mobileye $15.3B
- 2017-2022 Mobileye 在 Intel 內**結構性隔離**（Israel-based / 品牌獨立 / 商業模式自主）
- 2022/10 Mobileye **spin off IPO**

教師判斷的應驗：Intel 認識到母合錯位後**沒走內部 ventured + dissolved 的 [[entities/intel-NBI|NBI failure]] 路徑**，而是走 **acquire + isolate + spin off** 的「Christensen Quadrant C」路徑（[[references/christensen-overdorf-2000-HBR-disruptive-change|Christensen-Overdorf 2000 HBR]]）。

**Parenting Matrix 的處方**：ALIEN TERRITORY → 剝離 → Intel 真的做了。^[inferred]

## 跨案例應用

### [[entities/Marriott-International|Marriott]] — 30 brands portfolio
- Luxury / Premium / Select / Residences 多數在 **HEARTLAND**（hospitality operation 是 Marriott core capability）
- 但 LEGOLAND theme parks 對 Marriott 會是 ALIEN TERRITORY — 所以 Marriott 沒做主題樂園

### [[entities/Lego-Group|Lego]] — 1999-2004 多角化
- LEGO Studios（電影）/ LEGO Universe（MMOG）/ LEGOLAND（樂園）對 Lego 是 **VALUE TRAP**（子業務需要 entertainment expertise，Lego 母公司不會）
- 2005 LEGOLAND 賣給 Merlin Entertainments — 正確 ALIEN TERRITORY 處置

### [[entities/Alphabet|Alphabet]] Other Bets
- Waymo（自駕）/ Calico（抗衰老）/ Verily（醫療）對 Alphabet 母公司可能是 **VALUE TRAP**：子公司需要 deep domain expertise，Google search/ad 母公司不會
- 教師眉批：「**不是 Matrix，是 Google and non-Google**」 — 暗示 Alphabet 結構是承認 Other Bets 處於 ALIEN TERRITORY，**用 holding 結構處理而非整合**

### [[entities/Elon-Musk|Musk Empire]]
- Tesla + SpaceX + Twitter + Boring + Neuralink + OpenAI — 教師明點「**沒有 synergy**」
- 每個子公司對 Musk holdings 都是不同 industry → 多數 VALUE TRAP / ALIEN TERRITORY
- Musk 違反 parenting matrix 原則

### [[entities/Samsung-Electronics|Samsung]] — 1997 turnaround
- 砍 29,000 員工 + 賣 $2B 資產 — 剝離 ALIEN TERRITORY / BALLAST
- 保留 HEARTLAND（半導體 + 顯示器 + 手機）
- 對應 [[concepts/corporate-turnaround-strategy|turnaround 第 2 步 re-configuration]]

## 為什麼這個框架重要

1. **Corporate strategy 工具**：解釋為什麼 conglomerate 通常 underperform — **大部分 portfolio 是 ALIEN TERRITORY**
2. **M&amp;A 決策**：併購前先評估 parenting fit，避免事後 spin off 的失敗
3. **Spin-off / divestiture 決策**：何時該賣子公司 — ALIEN TERRITORY + BALLAST 都該賣
4. **連結 [[concepts/corporate-vs-business-strategy|corporate vs BU strategy]]**：corporate level 的本質是「**母公司能否增值**」這個問題
5. **連結 [[concepts/diversification-strategy|diversification strategy]]**：給「該不該多角化」一個診斷工具

## 與其他 corporate strategy 框架的關係

| 框架 | 視角 | 關係 |
|---|---|---|
| **Goold-Campbell Parenting Matrix** | 母公司增值能力 fit | **本頁** |
| **BCG Growth-Share Matrix** | 子業務市場成長 + 市占 | 不看母公司能力 — 較舊框架 |
| **GE-McKinsey 9-box** | 產業吸引力 + business strength | 同上，不看 parenting |
| **Ashridge Portfolio Display** | Goold-Campbell 同源、加入 strategic role | 同源 |
| **Porter 1987 HBR「From Competitive Advantage to Corporate Strategy」** | 4 種多角化策略 | 對應，但 Porter 偏 BU 視角 |

Goold-Campbell 的獨特貢獻：**強調母公司 capability vs 子公司 needs 的 fit**，而不只是 BU 表現。

## TL;DR

TCFD 由金融穩定委員會（FSB）2015 年成立、Michael Bloomberg 主席，提供企業向投資者揭露**氣候風險與機會對財務影響**的四大支柱框架（治理、策略、風險管理、指標與目標）。截至 2023-10，全球 4,855 家企業參採（年增 17%），亞洲超 50%，日本以 1,000+ 家居冠。2024 年起 TCFD 整體職責移交 [[concepts/ISSB-IFRS-S1-S2]]。

## 四大支柱

| 支柱 | 揭露內容 |
|---|---|
| **Governance（治理）** | 董事會與管理階層對氣候議題的監督 |
| **Strategy（策略）** | 氣候風險 / 機會在短中長期對業務、策略、財務規劃的影響 |
| **Risk Management（風險管理）** | 識別、評估、管理氣候風險的流程 |
| **Metrics & Targets（指標與目標）** | 評估與管理氣候風險的指標（如 Scope 1-3 排放、目標達成度） |

## 氣候風險分類

| 類型 | 子類 | 例 |
|---|---|---|
| **Physical Risk** | Acute（急性） | 颱風、洪水、熱浪導致工廠停擺 |
|  | Chronic（慢性） | 海平面上升、降雨模式長期改變 |
| **Transition Risk** | Policy & Legal | 碳費、CBAM、排放管制 |
|  | Technology | 低碳技術替代既有產品 |
|  | Market | 客戶偏好轉變、原物料價格 |
|  | Reputation | 漂綠指控、社運抵制 |

## 台灣監管

- **2020**：金管會「公司治理 3.0」首次納入 TCFD 揭露要求
- **2022 起**：全體上市櫃公司需依 TCFD 揭露氣候風險與措施
- **2023 年採用率**：444 家（年增 20.6%）
- **盤查時程**：2027 年前完成 GHG 盤查、2029 年前完成查證

## TCFD → ISSB 過渡

2023-06 IFRS 發佈 S1 / S2 後，TCFD 被定位為「末代框架」，2024 年起職責整體移交 ISSB。TCFD 4 支柱結構幾乎原封不動進入 IFRS S2。

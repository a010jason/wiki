# Hypercompetition

定義（D'Aveni）：「intense and rapid competitive moves… continuously creating new competitive advantages and destroying existing competitive advantages」。^[extracted]

對 Porter SCP 模型的根本挑戰：**因果方向反轉**。

## 對 [[concepts/porters-five-forces]] 的兩個鬆動

Porter 的 SCP 框架隱含兩個假設：(1) industry structure 驅動 competitive behavior；(2) industry structure 穩定。Hypercompetition 同時挑戰兩者：^[extracted]

| Porter 觀點 | Hypercompetition 觀點 |
|---|---|
| Structure → Conduct → Performance | Competition 反過來 **改變** structure |
| 找 attractive industry 然後佔位 | 沒有持續優勢，只有 series of transient advantages |
| Five Forces 是診斷工具 | Five Forces 是「上個時代的快照」 |

McGrath 把這稱為 **transient advantage**：競爭優勢的半衰期愈來愈短，企業要不斷啟動下一波，而不是死守一個 moat。^[inferred]

## Schumpeter 的「creative destruction 大風」

Schumpeter 的經典論點：競爭不是價格戰、不是市佔之爭，而是**創新破壞既有秩序**的過程。market leaders 被推翻不是因為對手更便宜，而是因為對手定義了新賽局。^[extracted]

實證錨點（Grant Ch8）：1912 vs 2018 全球前十大市值公司完全洗牌 —— 1912 全是 commodity / industrial（US Steel、Standard Oil、GE、Singer）；2018 全是 tech / platform（Apple、Alphabet、Microsoft、Amazon、Facebook、Tencent）。^[extracted]

## 與 [[concepts/dynamic-capabilities]] 的關係

Hypercompetition 是「外部現實」，dynamic capabilities 是「對應的內部能力」。Teece 三型（sensing / seizing / reconfiguring）正是為 hypercompetitive 環境設計的能力組合，與 [[concepts/VRIO-framework]] 那種靜態 resource analysis 形成對比。^[inferred]

## Winner-Take-All 例外

在 extreme scale economies + network externalities 強的產業（搜尋、社群、線上拍賣），「產業吸引力」這個概念失去意義 —— 一家拿走幾乎全部利潤，其餘接近零利潤。^[extracted]

→ 連 [[concepts/network-externalities]]、[[concepts/strategic-collisions]]、[[concepts/platform-competition]]。

## 醫療 AI 的判讀

醫療影像 AI 不是 hypercompetition 場景：FDA 510(k) approval、PACS integration、臨床 evidence 累積都拉長 advantage 半衰期。但 LLM 進場後（2022-）部分子場景（report drafting、structured data extraction）開始往 hypercompetition 滑 —— 模型 6 個月一代、moat 多半建在 data + workflow integration 而非演算法本身。^[inferred]

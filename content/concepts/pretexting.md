## TL;DR

Pretexting 指**假冒他人身分（社會工程手法）以取得敏感資訊**——通常是電信通話紀錄、銀行資料、個人檔案。最知名案例為 **2006 年 [[entities/Hewlett-Packard]] pretexting scandal**：HP 董事會為調查媒體洩密來源，雇用偵探對自家董事、高管及記者進行 pretexting，事發後 [[entities/Patricia-Dunn]] 辭職、多人遭刑事起訴，直接催生美國《Pretexting Prohibition Act》。

## 典型手法

```
1. 偵探打給電信公司，假裝是用戶本人
2. 提供用戶基本資料（生日、地址，從公開資源蒐集）
3. 取得通話紀錄、簡訊紀錄
4. 比對通話對象，推測洩密來源
```

## HP 案件時間軸（2005-2006）

| 時間 | 事件 |
|---|---|
| **2005 中期** | 董事會議內容開始被 WSJ 等媒體洩露 |
| **2005 末-2006 初** | 董事會（[[entities/Patricia-Dunn]] 授權）僱用調查公司進行 pretexting |
| **目標** | 9 位董事（含 [[entities/Tom-Perkins]]、[[entities/Carly-Fiorina]]）+ Mark Hurd + 多名記者 |
| **2006-05** | 知情者向加州檢察官舉報 |
| **2006-09-12** | [[entities/Patricia-Dunn]] 辭任董事長；Mark Hurd 接任 |
| **2006-10** | HP 認罪、支付民事罰款 USD 14.5M |
| **2006-12** | 加州檢察官對 Patricia Dunn 等 5 人提起刑事告訴 |
| **2007-03** | Patricia Dunn 罪名因健康因素撤銷 |

## 法律後果

- **加州 / 多州刑事化 pretexting**
- **聯邦《Telephone Records and Privacy Protection Act of 2006》**：將取得電信紀錄的 pretexting 列為聯邦罪
- **SOX 後治理啟示**：即使有 SOX，董事會仍可能做出嚴重失格決策

## 治理教訓

1. **手段不可蓋過目的**：為查洩密而做出比洩密更嚴重的違法
2. **獨立法律審查**：內部調查須有法務 / 外部律師事前審查
3. **董事會獨立性**：[[concepts/independent-director]] 需有質疑領導決策的勇氣
4. **隱私權 vs 機密保護**：保護董事會機密不能用詐騙手段

## 對台灣的啟示

- 台灣 2018 年起加強個人資料保護法、密件交易法
- 上市公司內部調查（如 [[concepts/competing-business-prohibition]] 競業違反）需遵守取證合法性

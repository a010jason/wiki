# Frame of Reference (FOR)

## What It Is

> Frame of Reference = 顧客用來評估公司 offering 的 benchmark（基準）。
> ^[extracted Ch07 p.11]

意涵：你不是被「客觀的真實」評估，而是被「客戶心中的對標物」評估。重設 FOR 是改變競爭規則。

## 為什麼 FOR 是策略級動作

選錯 FOR → 在錯的競爭組打輸

選對 FOR → 跳出原本 commoditize 的競爭

### 案例：Tesla

Tesla Roadster 早期定位是「跑車」（FOR = Porsche / Ferrari），不是「電動車」（FOR = Prius / Volt）。

意義：
- 跑車 FOR → 比加速、外型、駕馭感 → Tesla Roadster 比得過 Porsche
- 電動車 FOR → 比續航、性價比 → Tesla Roadster 比不過 Prius

選 FOR = 選戰場 = 選誰是對手。

### 案例：Facebook → Meta

教師批註：「FB → meta」是改變組織 infra 來**重塑競爭參照框架**（從 social network 切到 metaverse）。^[inferred from instructor annotation]

意義：
- 原 FOR = Snapchat / Twitter / TikTok（social media）→ 進入紅海
- 新 FOR = Apple / Microsoft（spatial computing platforms）→ 重設賽道

重設 FOR 的代價：要說服資本市場 + 消費者一起 buy in。Meta 改名後的股價跌幅顯示這個 reset 沒被市場接受。^[inferred — 隱含 wiki-challenge candidate]

## FOR 與 POD/POP 的關係

[[concepts/points-of-difference-and-parity]] 必須在 FOR 之內定義：

```
1. 選 FOR（與誰對標？）
2. 識別 Category POPs（同類必備）
3. 識別 Competitive POPs（中和對手 POD）
4. 建立 POD（3D 準則：Desirable / Deliverable / Differentiating）
```

意涵：沒 FOR 就沒 POD 與 POP — 「在哪個框架內差異化」決定 differentiation 的相關性。

## Straddle Positioning — 跨多個 FOR

當品牌同時對應多個 FOR：^[extracted Ch07 p.16]

範例：BMW M5「跑車 又 舒適」 — 跨「跑車」與「豪華 sedan」兩個 FOR。

**風險：Lowest Common Denominator** — 跨坐會掉入最低共同標準，失去定位銳利度。^[extracted]

教師批註：「最小公分母（最小公倍數）最低共同標準」。^[inferred from instructor annotation]

## Source 反例 / 質疑

- **FOR 不是行銷者單方決定的** — 顧客有自己的 mental categorization，行銷者只能 nudge 不能 dictate。Source 未明處理這個 power asymmetry。^[inferred — 隱含批評]
- **重設 FOR 的成功率** — Facebook → Meta 案的負面結果暗示 reset FOR 風險極高，但 Source 沒給 success criteria。^[inferred — 隱含批評]
- **多 FOR 在當代消費者腦中是常態** — 一個品牌在不同情境下 trigger 不同 FOR（同樣 iPhone 在工作 vs 娛樂情境下對標不同），單一 FOR 假設過簡。^[inferred]

## Jason 觀察：醫療 AI 的 FOR 選擇

EBM PACS / AI 的 FOR 兩條路：^[inferred — Jason 個人延伸]

### FOR 1：「AI 模型」

對標 GE Edison / Aidoc / Heartflow 等國際 AI 廠商。

- POD 候選：模型精度、可解釋性、多 modality
- 競爭點：完全在模型本身

問題：EBM 在這個 FOR 內不易超越國際大廠（規模、資料、人才）。

### FOR 2：「臨床流程助理」

對標 PACS vendor 自家的 AI module（Sectra AI、GE PACS AI）+ 院內 IT 自建。

- POD 候選：與 PACS 工作流深度整合、本地化（健保碼）、繁中報告、與多家 PACS 互通
- 競爭點：整合度與本地化，不是模型本身

EBM 在這個 FOR 內有結構性優勢。

**推論：EBM 應該主動 reset FOR 從 1 → 2**，避開「AI 廠商比拚模型」的紅海，進入「PACS 整合度比拚」的相對 niche 戰場。這就是 [[concepts/strategic-innovation]] 的 reframing 動作。

## TL;DR

**碳中和（Carbon Neutrality）= 減量 + 抵換**，可包含購買碳權達標；**淨零排放（Net Zero）= 全溫室氣體減量到極限 + 殘餘排放透過移除（removal）抵銷**，標準更嚴格。「先減量再抵換」為核心倫理精神，單純購碳權而未減量不視為完整實踐。

## 兩者差異

| 項目 | 碳中和 | 淨零排放 |
|---|---|---|
| **氣體範圍** | 通常僅 CO2 | 全 7 種溫室氣體（CO2、CH4、N2O、HFCs、PFCs、SF6、NF3） |
| **抵換方式** | 可大量購買碳權達標 | 殘餘排放需用**移除**（自然吸收 / 直接空氣捕集 / 生質能碳捕捉）抵銷 |
| **減量強度** | 較鬆 | 較嚴（需符合 1.5°C 路徑） |
| **代表標準** | PAS 2060 / ISO 14068 | SBTi Net-Zero / IPCC 1.5°C 路徑 |

## 達成路徑

```
BAU 排放 → GHG 減量 (reduction) → 移除抵換 (removal offsets) → 淨零
```

## 國際承諾時程

| 時間 | 事件 |
|---|---|
| **2015** | 巴黎協定：1.5-2°C 目標 |
| **2018** | IPCC 1.5°C 報告：需 2030 年減半、2050 年淨零 |
| **2023 (COP28)** | 首次「轉型脫離化石燃料」決議 |

## 全球升溫預測

- **2010 預測**：本世紀末 3.7-4.8°C
- **2023 GST 預測**：本世紀末 2.4-2.6°C（已進步但仍超 1.5°C 目標）

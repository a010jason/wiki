# Brand Extension

## What It Is

**Brand Extension** = 用現有 brand 名稱進入新產品 / 新類別。^[extracted Ch10 p.23]

兩種子類型：^[inferred Ch10]
- **Line extension**（線內延伸）：同類別內加 SKU（Coke → Diet Coke → Cherry Coke）
- **Category extension**（跨類延伸）：跨進新類別（Virgin 從航空 → 音樂 → 銀行）

## 優勢

Kotler 列出 brand extension 的優勢：^[extracted Ch10 p.23]

| 優勢 | 機制 |
|---|---|
| **Brand equity transfer** | 新產品借用母品牌的 awareness 與 trust |
| **降低新品上市風險** | 通路接受度高、消費者試用門檻低 |
| **減少廣告需求** | 不必從零建立 awareness |
| **加速 distribution** | 通路商更願意鋪貨 |
| **共享行銷資源** | 母品牌的廣告 spill-over 到新品 |

## 劣勢：Brand Dilution（品牌稀釋）

Brand extension 的核心風險 — **brand dilution**：^[extracted Ch10 p.23]

- 母品牌的明確 association 被稀釋（消費者開始混淆「這 brand 到底代表什麼」）
- 失敗的 extension 反向損害母品牌
- 過度 extension → mantra 失焦

經典反例：**BIC**^[extracted Ch10 p.22]
- BIC 從**原子筆**（成功）
- → 打火機（成功）
- → 拋棄式刮鬍刀（部分成功）
- → BIC 香水（**慘敗**）— 拋棄式低價 brand 與奢侈品香水文化衝突，導致 brand dilution

## Brand Repositioning（品牌重新定位）

當 extension 過度或環境變化，品牌可選擇 repositioning：^[extracted Ch10 p.21]

兩條路線：
1. **回歸基本**（back to basics）— Burberry 案例：1990s 在年輕人圈被當街頭潮牌，影響高端定位；2000s 後 repositioning 回奢侈精品。^[extracted Ch10 p.22]
2. **再創新策略**（reinvention strategy）— 徹底重塑 brand 形象與目標 segment

## Extension 成功要件

雖然 source 沒給明確 checklist，但隱含三個條件：^[inferred Ch10]

1. **Fit（契合度）**：新類別與母品牌核心 association 一致或相鄰
2. **Quality consistency**：新類別品質不能低於母品牌
3. **Mantra alignment**：新品與 [[concepts/brand-mantra]] 不衝突

例：Apple 從 Mac → iPod → iPhone → iPad 高度 fit（都是「優雅消費電子」）；Apple Car 若推出，fit 仍在但 quality consistency 風險高。

## Source 反例 / 質疑

- **Fit 沒可操作定義**：Apple Car 跟 Mac 算 fit 嗎？source 沒提判準。^[ambiguous]
- **Virgin 經驗的特殊性**：Virgin（航空 → 音樂 → 銀行 → 電信 → 太空）這種極端 category-stretching 為何不失敗？因為 brand mantra 就是「叛逆 / 顛覆」— mantra 本身就含「跨領域」基因。普通 brand 不能複製。^[inferred — Jason 觀察]
- **Brand dilution 滯後**：稀釋通常 3-5 年才顯現，期間 extension 仍貢獻短期收入；管理層常被短期收入綁架而不停 extension。^[inferred]
- **Sub-brand 是否算 extension**：Toyota Lexus 是 sub-brand 還是 extension？邊界模糊。^[ambiguous]

## Jason 觀察：醫療 AI brand extension 的陷阱

醫療 AI 廠商常陷的 extension 誤區：^[inferred — Jason 個人延伸]

- **從影像 AI extension 到 EMR AI**：表面 fit，實則使用情境（影像科 vs 內科）完全不同，brand mantra「速度」可能在 EMR 場景無效
- **從醫療 extension 到一般 healthcare**（fitness app / 健檢 / 保險）：trust 機制不同
- **從單一 modality extension 到多 modality**（X-ray → CT → MRI → 超音波）：通常 fit 強

關鍵：醫療 AI 的 extension 應**以 workflow 而非 modality** 為單位 — 同一 workflow 內 extension（如影像 → 報告 generation）的 fit 高於跨 workflow extension（如影像科 → 麻醉科）。

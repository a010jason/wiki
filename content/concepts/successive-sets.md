# Successive Sets

## What It Is

Kotler 16e Ch03 Figure 3.4 — 消費者在 [[concepts/buying-decision-process-consumer]] 的 Evaluation 階段把選項從 Total Set 漏斗收斂到最終 Choice：^[extracted Ch03 p.26-27]

```
Total Set
   ↓ (consumer 不知道的會掉)
Awareness Set
   ↓ (不符合 basic criteria 的會掉)
Consideration Set
   ↓ (沒進 finalist 的會掉)
Choice Set
   ↓ (只剩一個)
Choice
```

## 範例（手機品牌）

Kotler 用手機為例：^[extracted Ch03 p.27]

| 階段 | 內容 | 行為 |
|---|---|---|
| **Total Set** | Apple / Samsung / Google / LG / HTC / Huawei / OnePlus（7 個） | 市場上所有品牌 |
| **Awareness Set** | Apple / Samsung / Google / LG / HTC（5 個） | 去掉沒聽過的 Huawei、OnePlus |
| **Consideration Set** | Apple / Samsung / Google / LG（4 個） | 去掉不在意的 HTC |
| **Choice Set** | Apple / Samsung（2 個） | 認真比較的 finalist |
| **Choice** | Apple（1 個） | 最終購買 |

## 行銷者在各層的工作

| 層 | 行銷工作 | 對應工具 |
|---|---|---|
| Total → Awareness | **建立品牌知名度**（Communication、PR、廣告 reach） | 7Ts 的 Communication |
| Awareness → Consideration | **建立 category POP**（讓客戶覺得「這也是個選項」） | [[concepts/points-of-difference-and-parity]] POP |
| Consideration → Choice Set | **建立 POD**（在比較中突出） | POD 3D 準則 |
| Choice Set → Choice | **贏在最後一步**（價格、業務、最後說服） | Incentives + Communication |

## 與其他模型的關係

### vs [[concepts/points-of-difference-and-parity]]

POP 決定能否進 Awareness Set（被視為同類），POD 決定能否進 Choice Set（被視為突出選項）。

### vs Funnel Marketing（Awareness / Interest / Desire / Action 等 AIDA）

Successive Sets 是 AIDA 的更具體版本：

| AIDA | Successive Sets |
|---|---|
| Awareness | Awareness Set |
| Interest | Consideration Set |
| Desire | Choice Set |
| Action | Choice |

但 Successive Sets 是「選項集合的縮小」，AIDA 是「客戶情緒的演進」 — 軸不同。

### vs [[concepts/customer-journey-map]]

Customer Journey 是時間軸 + 多 touchpoint，Successive Sets 是 evaluation 階段內的「集合收斂」 — 是 Customer Journey 的子步驟。

## Source 反例 / 質疑

- **線性 funnel 在數位時代是否還適用** — TikTok / Instagram 演算法推送使「awareness → consideration」可能單一 swipe 完成；衝動購買跳過 consideration。^[inferred — 隱含批評]
- **多品牌平行考慮** — Successive Sets 假設逐層淘汰，但實際決策可能在 Consideration Set 中反覆比較，不是單向淘汰。^[inferred]
- **集合範圍因人而異** — 同樣手機市場，年輕人的 Awareness Set 可能 10 個品牌，老年人可能 2 個。Source 未處理 segment 差異。^[ambiguous]

## Jason 觀察：醫療 AI 的 Successive Sets

醫療 AI 採購的 set 範圍與消費品不同：^[inferred — Jason 個人延伸]

| 階段 | EBM 在台灣 PACS AI 採購場景 |
|---|---|
| **Total Set** | 全球 + 本地醫療 AI 廠商 ~30+ 家 |
| **Awareness Set** | 通常 5-10 家（國際大廠 + 本地有 KOL 背書的） |
| **Consideration Set** | 通常 3 家（RFP 邀請） |
| **Choice Set** | 通常 2 家（finalist） |
| **Choice** | 1 家中標 |

關鍵：**Awareness Set 是最大瓶頸** — 進不到醫師 / IT 主管的 awareness set 就被 game over。手段：

1. 學會研討發表（KOL endorsement）
2. 院內 demo session（user touch）
3. 醫材展 booth（buyer awareness）
4. 醫療科技媒體報導（public source）

直接拼價格或模型精度（Choice Set 之爭）是 stage 4 的事，前面 stage 1-3 沒做好沒機會打。

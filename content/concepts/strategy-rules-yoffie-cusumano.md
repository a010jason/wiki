# Strategy Rules — Yoffie &amp; Cusumano 5 法則

David Yoffie（HBS）+ Michael Cusumano（MIT Sloan）2015 出版《Strategy Rules: Five Timeless Lessons from Bill Gates, Andy Grove, and Steve Jobs》。從 3 位 tech 巨頭 CEO 訪談 + 案例研究，**提煉出 5 條跨時代適用的策略法則**。中譯《我們這樣改變世界：賈伯斯、比爾蓋茲與葛洛夫給下一代創業者的五堂必修課》。^[extracted]

> 教師核心 framing（[[references/HBS-9-722-439-Musk-doubling-down-case|Musk Doubling Down lecture]]）：把 Yoffie 5 rules 對應到**[[concepts/sun-tzu-five-fundamentals|孫子兵法「道天地將法」]]** — 東西方策略框架對接。詳見 [[synthesis/yoffie-five-rules-vs-sun-tzu-five-fundamentals]]。^[teacher-annotation]

## 5 條法則

### Rule 1：Look Forward, Reason Back（展望未來，回推現在）
- 對應孫子兵法：**道**
- 註解：Games（佈局）/ Priority（投資優先順序）/ set boundaries
- 思考方式：先決定未來目標狀態，再回推現在該做什麼
- 詳見 [[concepts/look-forward-reason-back]]

### Rule 2：Make Big Bets, Without Betting the Company（勇敢下大注，但不讓公司身陷險境）
- 對應孫子兵法：**天地**
- 註解：Context / Scope / **Self-fulfilled prophesy（自我實現預言）**
- 思考方式：押大注但保留 fallback；下注金額不超過公司可承受極限
- 詳見 [[concepts/big-bets-without-betting-company]]

### Rule 3：Build Platforms and Ecosystems—Not Just Products（創造產業平台與生態系，不只產品）
- 對應孫子兵法：**法**
- 註解：rules / BU vs platform / value chain / networks / corp-strategy
- 思考方式：產品 → 平台 → 生態系，每階段 leverage 不同
- 詳見 [[concepts/platforms-and-ecosystems-not-products]]

### Rule 4：Exploit Leverage and Power—Play Judo and Sumo（善用巧力與蠻力）
- 對應孫子兵法：**勢**
- 註解：capability
- 思考方式：判斷自己是 sumo（重武器）還是 judo（巧勁），不同戰術
- 詳見 [[concepts/judo-and-sumo-strategy]]

### Rule 5：Shape the Organization around Your Personal Anchor（根據自身獨特的強項打造組織）
- 對應孫子兵法：**法**
- 思考方式：組織該圍繞 CEO 的獨特能力設計，而非 best practice
- 詳見 [[concepts/personal-anchor-organization]]

## 對 3 位案例 CEO 的具體應用

### Bill Gates (Microsoft)
- Rule 1: Look Forward → Windows + Office 雙平台
- Rule 2: IBM PC OS 合約是 big bet（賭未來 PC 普及）
- Rule 3: Office suite + DOS/Windows API 是 platform/ecosystem
- Rule 4: Judo vs IBM；Sumo vs Netscape
- Rule 5: Engineer-led culture

### Andy Grove (Intel)
- Rule 1: 1985 退出 DRAM 進入 microprocessor 是「展望未來，回推現在」典範
- Rule 2: Strategic Inflection Point 框架（Only the Paranoid Survive）
- Rule 3: Intel Inside + ecosystem partner
- Rule 4: Sumo（規模 + Moore's Law 投資）
- Rule 5: OBM (Operating by Objectives) — Grove 直接管理風格

### Steve Jobs (Apple)
- Rule 1: 2001 Digital Hub Strategy 是經典 look-forward
- Rule 2: iPhone 是 big bet（壓 Apple 的命）
- Rule 3: App Store + iOS 是 platform/ecosystem
- Rule 4: Judo vs Microsoft；Sumo vs Sony
- Rule 5: Founder-mode + design-led；Jonathan Ive 配對

### Elon Musk（教師延伸 — 4th 比較對象）
詳見 [[entities/Elon-Musk]] 對應，但教師質疑 Musk 違反多條規則：
- Rule 2 違反：**Gigafactory bet 接近「betting the company」越線**
- Rule 3 缺：**Musk Empire「沒有 synergy」**（7 公司各自為政）
- Rule 5 過頭：Personal anchor 變 personal hubris（Twitter 收購）

## 教師核心眉批（[[references/HBS-9-722-439-Musk-doubling-down-case|Musk lecture]] p.1）

> 「**孫子兵法，領導者五事：道天地將法**」 — 把西方 5 rules 對應東方五事 ^[teacher-annotation]

> Rule 1 → **道**（Games / Priority / Set boundaries）
> Rule 2 → **天地**（Context / Scope / Self-fulfilled prophesy）
> Rule 3 → **法**（rules / BU vs platform / value chain / networks / corp-strategy）
> Rule 4 → **勢**（capability）
> Rule 5 → **法**

## 為什麼這個對接重要

1. **5 vs 5 對應**：兩個獨立框架都選 5 個維度，可能反映管理 / 領導本質有約 5 個核心張力
2. **timeless 跨文化驗證**：Yoffie 5 rules 從美國 tech 提煉；孫子兵法 2,500 年前；若兩者收斂到同一組維度，可信度更高
3. **教學應用**：對 Jason（中文背景 + 美式 MBA 框架雙重訓練）特別有用 — 用熟悉的中文文化框架幫助理解陌生的西方策略概念
4. **批判邊界**：是否真的 5 對 5？「天地」放 Rule 2 是教師詮釋（context = 天地），但孫子原意「天時地利」更接近 Rule 1 的 framing — 對應不完美 ^[inferred]

## Open Questions（待 wiki-challenge）

- **5 vs 5 對應是否成立？** 教師把 Rule 2 對 天地、Rule 3 對 法、Rule 5 對 法 — 「法」用兩次，可能不是嚴格 1-to-1 ^[inferred]
- **「Timeless」是否誇大？** 平台時代 winner-takes-all 加劇，Rule 4 judo strategy 是否仍適用？^[inferred]
- **Musk 違反多條規則卻仍成功**（至少 Tesla / SpaceX 在 2022 商業上成功）— 是 Yoffie rules 過時還是 Musk exception？^[ambiguous]

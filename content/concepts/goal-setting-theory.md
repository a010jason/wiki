# Goal-Setting Theory

Goals = primary drivers of **intensity** and **persistence** of effort。**Specific and Difficult Goals** > do-your-best > easy > no goals。^[extracted]

Locke & Latham (1990) *A Theory of Goal Setting and Task Performance*；35 年回顧 Locke & Latham (2002), *American Psychologist* 57:705-17。

## 核心曲線：Goal Difficulty 倒 U 型

```
Performance
   │       ___
   │      /    \
   │     /      \____
   │    /
   │___/
   └──────────────────→ Difficulty
     Easy  Moderate  Difficult  Impossible
```

最佳 motivation 出現在 **Difficult**（但 attainable）— 過 Impossible 後 performance 反崩。^[extracted]

## Mediator 路徑

```
Specific/Difficult Assigned Goal
  → Self-Set Goal
  → Intensity of Effort / Persistence / Task Strategies
  → Task Performance
```

## Moderators

- **Feedback**：updates on progress
- **Task Complexity**：複雜任務的 goal effect 稀釋（Wood, Mento & Locke 1987 meta-analysis）
- **Goal Commitment**：接受並決心達成的程度

## SMART 批判

Source 自承 **SMART**（Specific / Measurable / Achievable / Results-based / Time-sensitive）**遺漏了關鍵的 "Difficult"**。Achievable 反而把 difficulty 拉低 → motivation 衰減。^[extracted]

## 案例

- **Microsoft**：每位員工識別 5-7 SMART goals → rewards 直接連到 goal achievement。但教材直指 SMART 缺 Difficult。^[extracted]
- **IBM Checkpoint app**：舊系統「Jan 設目標 → Dec 評分」"irrelevant by December"；改為 shorter-term goals + quarterly feedback + 5 criteria（business results / impact on client / innovation / personal responsibility / skills）— 提供 mid-cycle feedback moderator。^[extracted]
- **SAP**：強調 honest + open communication，確保員工理解貢獻 organizational goal 的 why — Commitment moderator。^[extracted]

## 與其他績效工具的關係

- **[[concepts/OKR]]**：Specific + Difficult（"stretch"）+ cascading + Feedback 全集中體現
- **[[concepts/MBO]]**：Drucker / Intel 原型；偏 Results-based，較少 difficult emphasis
- **[[concepts/forced-ranking]]**：把 difficulty 轉成 relative comparison，但長期 erosion（GE 案例 16% → 6% → ~0%）

## 反例 / 質疑

- Goal-setting 與 [[concepts/equity-theory]] 衝突場景：若 goal 過高而 P→O 弱 + 同儕 reward 高 → 員工放棄。
- 高 commitment 員工被指派 stretch goal 可能 burnout — 與 [[concepts/stress]] hindrance stressor（role overload）邊界模糊。^[inferred]
- 跨文化：assigned vs collective goal 在 individualism vs collectivism 文化效果差異大（Ch6 OB Internationally）。^[extracted]

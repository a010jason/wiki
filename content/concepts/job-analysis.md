# Job Analysis（工作分析）

## 為什麼需要 Job Analysis

[[concepts/task-performance|Task Performance]] 定義為「將組織資源轉化為產品 / 服務的行為」—— 但**哪些行為**算 task performance？不能靠主管直覺、不能靠員工自陳，需要系統性的方法。^[inferred]

Job analysis 是把抽象的 task performance 落到具體 behavior list 的標準工具，後續產出供：^[extracted]
- Job description / Job specification
- 招募條件
- Training learning objectives
- Performance evaluation measures
- 連動到 [[concepts/performance-management]] 與後續所有 HR 流程

## 教科書三步驟

來源：Colquitt OB Ch2 p.57-59。^[extracted]

### Step 1：List Activities

資料來源三選一或合用：
- **Observations**（直接觀察）
- **Surveys**（問卷）
- **Interviews**（訪談）

### Step 2：SME Rating

由 Subject Matter Expert（通常是 incumbents、supervisors、HR specialists）就每個 activity 打分兩個維度：
- **Importance**（重要性）
- **Frequency**（頻率）

### Step 3：高分活動寫入 HR 系統

兩個出口：
- **Training learning objectives**
- **Performance evaluation measures**

## 教學簡化版（四步驟，p.60）

教科書另給一個四步驟操作法，適合課堂與小型組織：^[extracted]

1. Divide job into major **dimensions**
2. List **2 key tasks per dimension**
3. **Rate** frequency & importance
4. 用最高者**定義 task performance**

## O*NET OnLine 工具

美國勞動部主導的標準職業資料庫，每個 occupation 含：^[extracted]
- Tasks
- Tools & Technology
- Knowledge
- Skills
- Abilities
- Work Activities
- Work Context

**示範**：35-3031.00 Waiters and Waitresses — 含 Banquet Server / Cocktail Server / Food Runner / Room Service Server 等 sample job titles，列出 24 個 tasks。^[extracted]

## 練習範例（教科書）

### Server（餐廳服務生）

4 major dimensions × 2 tasks/dimension。^[extracted]

### Fast Food Worker

四維度示意（資料來源：The Balance）：^[extracted]
1. Operate cash register
2. Serve customers
3. Prepare and cook food
4. Provide excellent customer care

Median wage $8.85/hr。^[extracted]

## Boundary / 待批判

- **SME bias**：incumbents 傾向 over-rate own activities — source 未討論 ^[ambiguous]
- **快速變動職務的失效**：AI / tech 職務每年 task 組合變動大，job analysis 結果半衰期短 ^[inferred]
- **O*NET stale 問題**：source 用 2015 updated 截圖，未討論資料對新興職務的覆蓋限制 ^[ambiguous]
- **三步法 vs 四步法的並列**：source 同時列兩套但未說明何時用哪套，邊界模糊 ^[inferred]
- **量化 vs 質性的選擇**：observations / surveys / interviews 三選一的決策準則 source 未給 ^[ambiguous]

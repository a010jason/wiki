# 象、數、理 — Epistemology of Financial Ratios

**教師原創跨領域 epistemology 框架**（[[references/HBS-9-703-497-Zara-case|Zara lecture]] Reading Financial Ratios slide）— 把財報詮釋 + 陰陽五行 + Popper 三世界**三套框架對接**，是 Jason wiki 內最跨領域的教師原創 framing 之一。^[teacher-annotation]

> 教師原話：
> 「**Epistemology 認識論（知識論）/ Prediction**」
> 「**Calculation is straightforward（數）**」
> 「**Interpretation requires judgment（象）**」
> 「**Judgment is sharpened by experience（理）**」
> 「**陰陽五行即是「象、數、理」。**」
> 「**凡事有定，定中有象，象中有數，數中有理。**」
> 「**Note: Popper's three worlds**」
> ^[teacher-annotation]

## 三層對應表（教師核心）

| 層 | 內涵 | 財報層級 | 陰陽五行對應 | Popper World |
|---|---|---|---|---|
| **數** | Calculation is straightforward | 計算 — ROE / ROA / Margin 數字本身 | 五行的「行」 | **World 1**（物理 / 數字事實） |
| **象** | Interpretation requires judgment | 詮釋 — 數字背後的故事、業務含義 | 五行的「象」（卦象/形象）| **World 2**（主觀心理 / 詮釋） |
| **理** | Judgment is sharpened by experience | 判斷 — 跨脈絡跨產業的洞察 | 五行的「理」（道理/規律）| **World 3**（客觀知識體 / 累積智慧） |

## 教師核心命題

> 「**凡事有定，定中有象，象中有數，數中有理。**」

層級遞進關係：
1. **凡事有定** — 任何現象都有規律性（不是隨機）
2. **定中有象** — 規律呈現為現象（可觀察）
3. **象中有數** — 現象可量化（可測量）
4. **數中有理** — 數字背後有道理（可詮釋）

逆向（學習路徑）：**數 → 象 → 理**（從計算到詮釋到判斷）

## Zara 案例應用（教師主例）

| Zara 財報 | 數 | 象 | 理 |
|---|---|---|---|
| Operating margin 21.66%（vs Gap 2.44%）| 21.66% | Zara 比 Gap 賺更多 | 垂直整合 + Quick Response 是高 margin 根源 |
| Asset Turnover 124.76%（vs H&amp;M 195.56%）| 124.76% | Zara 資產周轉低於 H&amp;M | 但 Zara 自有店面 + La Coruña 工廠是高品質資產不該追周轉 |
| Inventory 比同業少 50% | 50% | 庫存效率高 | 「**Achieve Zero Inventory**」 + 6 件 / 款 freshness + scarcity 心理 |
| Advertising 0.3%（業界 3.1%）| 0.3% / 3.1% | 不做傳統廣告 | 大店 + 貴地段 = word-of-mouth + 寄生高級品牌廣告 |
| 76% 股票市值反映未來成長期望 | 76% | 股價遠高過當前 earnings | 市場相信 Zara fast fashion 的可持續成長 |

教師眉批：「**全部都可以被學 → 但合起來學不來 / Zara Psychology**」 — **理**的層級無法被簡單複製，因為它是 capabilities bundle 的 emergent property。^[teacher-annotation]

## 與 Popper's Three Worlds 對接

Karl Popper（1972）三世界框架：

| Popper World | 內容 | 教師對應「象數理」 |
|---|---|---|
| **World 1** | 物理世界（physical states / objects） | **數**（客觀數字 / 事實） |
| **World 2** | 心理世界（subjective experiences） | **象**（個人詮釋 / 判斷） |
| **World 3** | 客觀知識（theories, books, abstract objects） | **理**（累積智慧 / 跨脈絡知識） |

教師：「**Note: Popper's three worlds**」 — 暗示「象數理」是中國古典版本的 Popper 三世界 epistemology。

## 與 教師另一框架 的關係

教師在 [[references/HBS-booking-com-case|Booking case]] 提：「**Survey → 果果造因 / Database → GIGO / Experiment → Cause-effect**」

「象數理」可以對應這條因果階梯：
- **數** ≈ Database（純資料計算，GIGO 風險）
- **象** ≈ Survey（主觀詮釋，可能果果造因）
- **理** ≈ Experiment / Reasoning（真正建立因果）

但「象數理」更強調**從數字到智慧的累積過程**，而 causal inference vs correlation 強調**因果效力的階梯**。

## 為什麼這個框架重要

1. **East-West epistemology 對接**：陰陽五行 + Popper 是少見的跨文化哲學接合
2. **教學節奏**：給中文背景學員一個熟悉的 anchor 理解 financial ratio analysis
3. **強調 interpretation over calculation**：MBA 多訓練「數」（excel modelling）而忽略「象 / 理」 — 教師明點要從「數」往「象」「理」走
4. **連結 Zara 不可模仿性**：「全部可學但合起來學不來」的本質是**理層級的整合**無法被分解複製
5. **Jason 個人視角**：作為 PM，**數**是 dashboard / KPI；**象**是用戶訪談 / 質性洞察；**理**是策略判斷 — 三層都需要

## 反例 / 邊界條件

- **不適合 quick decisions**：「象數理」是 deep epistemology，急著做決定時用不上
- **跨文化障礙**：對非中文背景學員，「陰陽五行」可能像神秘主義 — 妨礙嚴肅討論 ^[inferred]
- **教師原創或經典引用？** 「凡事有定，定中有象，象中有數，數中有理」教師標示但**未引出處**；可能是《易經》/《周易》/《道德經》延伸或教師自創 ^[ambiguous]
- **與西方框架的關係**：類似 Aristotle epistēmē / technē / phronēsis 三分（科學知識 / 技藝 / 實踐智慧）；但「數象理」更線性 ^[inferred]
- **被詬病的「玄學嫌疑」**：陰陽五行在現代被視為非科學，硬接 Popper 可能被批 epistemologically incoherent ^[inferred]

# Maslow's Hierarchy of Needs

## What It Is

Abraham Maslow 1943《A Theory of Human Motivation》提出的五層需求金字塔，被 Kotler 16e Ch03 Figure 3.2 作為消費者動機的核心 visual：^[extracted Ch03 p.12]

```
       /\
      /  \    5. Self-actualization (自我實現)
     /----\
    /      \  4. Esteem (尊重 / 認同 / 地位)
   /--------\
  /          \ 3. Social (歸屬感 / 愛)
 /------------\
/              \ 2. Safety (安全 / 保護)
----------------
                 1. Physiological (生理 / 食物 / 水 / 居所)
```

意涵：低層需求未滿足前，高層需求不會成為主導動機。

## 五層細節

### 1. Physiological（生理）

最基本：食物、水、睡眠、居所、空氣。

行銷應用：賣保命的東西（基本食品、藥品、住宅）— 用「不可缺」訴求。

### 2. Safety（安全）

身體安全 + 經濟安全 + 健康。

行銷應用：保險、警報系統、健保。

### 3. Social（社會 / 歸屬感）

被群體接受、愛與被愛、友誼。

行銷應用：社群媒體、會員、社交活動。

### 4. Esteem（尊重）

自尊、認同、地位、成就。

行銷應用：奢侈品、稱頭職位、獎項。

### 5. Self-actualization（自我實現）

實現潛能、創造、成長。

行銷應用：教育、藝術、極限運動、捐贈。

教師批註：NIKE "Just Do It" / firefighter 圖示在第五層位置 — 訴求 self-actualization。^[inferred from instructor annotation]

## Motivation = Need 被激起到一定強度

Kotler 強調：^[extracted Ch03 p.13]

> A need becomes a motive when it is aroused to a sufficient level of intensity to drive us to act.

意涵：需求人人都有，**激起到動機**才會驅動購買。行銷者的工作是「激起」(activate) 既有需求，不是創造新需求。

## Needs / Wants / Demands 階梯

Kotler 把 Maslow 整合到三階梯：^[extracted Ch03 p.11]

| 階梯 | 定義 |
|---|---|
| **Needs** | basic human requirements（biological + psychological） |
| **Wants** | needs 加上具體形式（口渴 → 想喝 Coke） |
| **Demands** | 有支付能力的 wants |

意涵：行銷不創造需求（needs 是 given），行銷塑造 wants 的具體形式 + 把 wants 變成 demands（讓人付得起）。

## 批判 / Source 未提的反例

- **Maslow 本人晚年加上 Transcendence（超越自我）為第六層** — Kotler 未提。^[inferred — Maslow 1969 文獻]
- **跨文化研究 (Tay & Diener 2011)** 顯示需求並非嚴格 hierarchical — 低收入國家可能 social / esteem 與 physiological 同時滿足，與 Maslow 預測不一致。Kotler 未提。^[inferred — 隱含批評]
- **集體文化 vs 個人文化的差異** — 集體文化（如台灣、日本）可能 Social 高於 Esteem，反序。^[inferred]
- **行為經濟學的時間貼現視角** — 餓肚子的人會犧牲長期 self-actualization 換短期 physiological satisfy，這是真實但 Maslow 沒處理的 dynamic。^[inferred]

## Jason 觀察：Maslow 套用到醫師採用 AI 工具

醫師對 AI 工具的需求層次：^[inferred — Jason 個人延伸]

| Maslow 層 | 醫師對 AI 工具的對應需求 |
|---|---|
| **Physiological** | 「AI 不會增加我加班時間」（基本工作負荷不變） |
| **Safety** | 「AI 不會誤診」「不會被告」（執業安全） |
| **Social** | 「同行也在用」（學會 norm + KOL 背書） |
| **Esteem** | 「先進科技院內 KOL」（professional reputation） |
| **Self-actualization** | 「我是教學者 / 創新者 / 研究領頭者」（professional identity） |

意涵：EBM 行銷不能只訴求 Esteem / Self-actualization（多數醫療 AI 廠商的 framing 失誤）— 必須先處理 Safety（責任歸屬、認證）與 Physiological（不增加工作量）。

跳級風險：直接訴求 "AI 讓你成為下一代醫師"（self-actualization） → 失敗，因為 Safety 未滿足。

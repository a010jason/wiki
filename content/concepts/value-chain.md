# Value Chain（價值鏈）

## 框架

Porter 把企業活動拆解成 **value chain**，每個環節都是潛在的價值創造或成本來源。Grant Ch7 的汽車製造業 value chain：^[extracted]

```
Purchasing → R&D, Design Engineering → Component manufacturing → Assembly →
  Testing, Quality control → Sales, Marketing → Distribution →
  Dealer support, Customer service
```

每個段都可獨立分析：^[inferred]
- 它增加多少**成本**？
- 它創造多少**獨特價值**？
- 它與相鄰段如何**連動**？

## Cost Analysis with Value Chain（5 步驟）

Grant Ch7：^[extracted]
1. **Identify** main value chain activities
2. **Allocate** total costs between activities
3. **Identify cost drivers** at each stage
4. **Identify linkages** between activities
5. **Identify opportunities** for cost reduction

→ 第 4 步「linkages」最常被忽略 —— 真正的降本機會常出現在**活動之間**而非活動之內。^[inferred]

## Differentiation Analysis with Value Chain

不只看自家 value chain，還要看**客戶的 value chain**：^[extracted]

Grant Ch7 引用 Can Manufacturer 案例：罐頭製造商 → 食品廠商：

| Linkage | 差異化機會 |
|---|---|
| 1. 獨特罐型設計 | 協助客戶（罐頭廠）行銷 |
| 2. 高製造容差 | 避免客戶罐裝線停線 |
| 3. 頻繁穩定送貨 | 讓客戶能採用 JIT |
| 4. 高效訂單處理 | 降低客戶訂購成本 |
| 5. 強技術支援 | 提升客戶廠房使用率 |

關鍵：**差異化不是只看你自己強在哪，要看「對客戶哪部分有用」**。^[extracted-from-margin]

Jason 邊註：「差異化和成本的連接點在 Value Chain → 應該要擴大 Value Chain 而不是單看產品」。^[extracted-from-margin]

## Activity System View（呼應 Strategic Fit）

[[concepts/strategic-fit]] Ryanair Activity System 是 value chain 的進階版：不只看單一鏈，看**互相連結的活動系統**整體。^[inferred]

→ Inimitability 來自 system，不是來自單一 activity。對手可以複製一個元素，無法複製整個系統。

## 對 PM 的意涵

讀競品時不只比產品 spec：^[inferred]
- 對方的 value chain 哪一段最便宜？
- 哪一段創造了客戶端 value？
- 我們的 value chain 哪一段是 leverage 點？

例（醫療業）：
- 對手的「客戶服務」段做得弱 → 你強化客服可建立差異化
- 對手的「教育訓練」段昂貴 → 你提供 self-service 文檔或 AI 教練可降本

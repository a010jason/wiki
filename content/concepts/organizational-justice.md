# Organizational Justice（四維度）

[[concepts/trust]] 的「行為證據」。員工對組織公平的感知透過四個獨立但互補的維度被判讀。^[extracted]

Source: Colquitt-LePine-Wesson Ch7。Meta-analyses: Cohen-Charash & Spector (2001) *OBHDP* 86:287-321；Colquitt, Conlon, Wesson, Porter & Ng (2001), *JAP* 86:425-45。

## 四維度

| 維度 | 焦點 | 規則 |
|---|---|---|
| **Distributive Justice** | 結果公平 | 依情境選 **equity**（個人生產力極大化）/ **equality**（團隊和諧）/ **need**（特定員工福祉） |
| **Procedural Justice** | 流程公平 | 6 規則：**voice**（發聲）/ **correctability**（申訴）/ **consistency** / **bias suppression** / **representativeness** / **accuracy** |
| **Interpersonal Justice** | 人際對待 | **respect rule**（尊嚴對待）/ **propriety rule**（不做不當言行）。極端違反 → abusive supervision |
| **Informational Justice** | 溝通公平 | **justification rule**（完整合理解釋）/ **truthfulness rule**（誠實坦率） |

## Distributive Justice 三 norm 的情境選擇

source 自承 **沒有 universal 答案** — equity / equality / need 哪個「公平」要看目標：^[extracted]
- 個人生產力極大化 → equity
- 團隊和諧 → equality
- 弱者福祉 → need

→ 直接連結 [[concepts/equity-theory]]（Adams 1965）。

## Procedural Justice 6 規則應用

- **Voice + Correctability** 是兩個最被研究的：員工有機會發聲 + 有機會申訴 → 即使結果不利，program 仍會被視為公平。^[extracted]
- **Deloitte 績效管理改革**：舊系統年耗 **2 百萬工時** + 評分主觀偏誤 → 改為 future-focused、peer/supervisor feedback、bias-suppression 三原則。^[extracted]
- **Accenture**：放棄 rigid ranking（避免 office politics 偏誤）→ performance development（員工與主管設一致目標 / app 即時 feedback）。^[extracted]

## Interpersonal / Informational Justice 案例

- **Trump 政府反例**：FBI Comey 看 cable news 才知被解職；Rex Tillerson 從 Twitter 上看到取代他的人選 — Informational 違反經典。^[extracted]
- **RadioShack**：透過電郵集體解雇 400 名員工 — Informational injustice 經典案例。^[extracted]
- **宏碁 Acer 2018 台灣**：對外稱「組織調整、營運優化」非裁員；內部信主旨「Lay-off」被員工曝光 — truthfulness rule 違反。^[extracted]
- **Honest & adequate explanations**（Informational justice）研究證實**顯著降低員工 retaliation**。^[extracted]

## 跨國 / 跨文化邊界

- **BBC pay 案例**（distributive）+ **Iceland 法律** 強制同酬認證 — 政府介入 distributive justice 的國家差異。^[extracted]
- 在 collectivistic culture（亞洲）對 procedural injustice 的容忍度可能高於 individualistic（US/EU），但 source 未直接給數據。^[inferred]

## 與 Equity Theory 的演進

[[concepts/equity-theory]]（Adams 1965）是 distributive justice 的祖先。後續研究發現「**過程**比結果更影響員工反應」 → 加入 procedural；再加入 **人際 + 資訊** 兩維，形成今天 4D 模型。^[inferred]

## Open Questions

- **AI / 演算法時代的 Justice**：Uber facial verification 2021 案例（MIT 2018 研究指 Microsoft Face API 對女性 + 深膚色辨識錯誤率較高）開啟「演算法公平」議題，但 source 未把它整合進 4 維框架。^[extracted]
- 跨文化 generalizability 多為 US sample 推論。
- Justice 量表的學校 grading 場景對職場移植性 source 未驗證。

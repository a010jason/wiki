# VRIO Framework

## 上層：Resource-Based View (RBV)

RBV 的主張：**企業應該往內看找競爭優勢，而不是往外看競爭環境**。^[extracted] 與 Industrial Organization (I/O) 觀點（如 [[concepts/porters-five-forces]]）互補：

- I/O：外部 → competitiveness 決定 performance
- RBV：內部 → 公司獨有的特性決定 performance

兩者不是對立，是兩個面向。

## VRIO 四問

VRIO 用 4 條檢驗一個資源或能力能否帶來**持續競爭優勢**：^[extracted]

```
       NO              NO              NO              NO
  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
  │ Valuable │ NO │   Rare   │ NO │Inimitable│ NO │Organized │ NO
  └────┬─────┘ →  └────┬─────┘ →  └────┬─────┘ →  └────┬─────┘ →
       ↓ YES           ↓ YES           ↓ YES           ↓ YES
                                                  Sustained Competitive
                                                       Advantage
   Competitive       Competitive      Temporary         Unused
  Disadvantage         Parity         Competitive    Competitive
                                       Advantage      Advantage
```

| 維度 | 問題 | 例 |
|---|---|---|
| **V**aluable | 資源能讓公司利用機會、避免威脅嗎？ | know-how |
| **R**are | 競爭對手沒有？ | 好員工 |
| **I**nimitable | 競爭對手難以模仿？ | 文化、歷史 |
| **O**rganized | 公司有組織起來去抓住價值？ | 系統、流程 |

**全 YES 才有 sustained competitive advantage**。^[extracted]

## Inimitable 的三種來源

最容易被忽視但最關鍵的是「Inimitable」。三種讓資源難以模仿的機制：^[extracted]

1. **History** —— 歷史路徑依賴。公司走過的路，對手回不去
2. **Numerous small decisions（causal ambiguity）** —— 大量微小決策的累積，連自己都說不清「為什麼會做成」，所以對手更難複製
3. **Socially complex resources** —— 涉及人際互動的資源（文化、信任、團隊默契）— **這正是 OB 研究的領域**

## OB 在 VRIO 中的位置

**OB 是 Inimitable 一柱的核心**：^[inferred]
- 文化、employee engagement、leadership 風格、團隊默契 — 都是 socially complex resources
- 對手可以挖角你的工程師、買你的設備，但**買不到你的組織氛圍**

## 經典案例

教科書引用：^[extracted]
- **Nvidia 文化**：「Nobody fails alone」、no hierarchy、team-centric — 創新動能來源
- **小林眼鏡**（台灣品牌）+ Apple Store —— inimitable 服務體驗

## 對 ebmtech 的延伸思考

> 註：以下是把框架套到自己工作的 hypothetical 思考，未跟主管或同事驗證。^[ambiguous]

醫療資訊業 VRIO 分析草稿：^[inferred]
- **Valuable** —— PACS / HIS 對醫院確實有價值（合規、效率）
- **Rare** —— 在台灣有限玩家，Sectra / GE / Philips / EBM 等
- **Inimitable** —— **這是關鍵**。技術可被模仿，但**長年累積與醫院的關係、客製能力、台灣健保理解** = socially complex
- **Organized** —— 視 EBM 內部組織能力

要繼續壓「Inimitable」優勢，方向是**深化客戶關係 + 文化資產 + 知識管理**，而非僅靠技術領先。

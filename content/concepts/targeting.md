# Targeting

## What It Is

> Targeting = 為「公司會為其優化 offering」的那群客戶下定義的流程。
> ^[extracted Ch06]

意涵：targeting 不是「賣給誰」，是「為誰優化整套行銷組合」。是 [[concepts/STP-framework]] 的 T。

## 三種策略邏輯（The Logic of Targeting）

Kotler 區分三種 market strategy：^[extracted Ch06 p.6-8]

| 策略 | 內容 | 案例 |
|---|---|---|
| **Mass marketing** | 忽略 segment 差異，整個市場用同一個 offer 打 | 早期 Coca-Cola |
| **Targeted marketing** | 對不同 segment 賣不同產品；極限是 **one-to-one** 銷售 | 多數現代品牌 |
| **Mass customization** | 在大規模生產的成本基礎上，仍能為每個客戶準備個別設計的產品 / 服務 / 方案 / 溝通 | Coca-Cola Freestyle 觸控飲料機 |

## Strategic vs Tactical Targeting 雙層

Kotler 16e 引入雙層 targeting 框架：^[extracted Ch06 p.9-10]

### Strategic Targeting（Why / When）

聚焦在「公司能否藉由 customizing offering 滿足其需求」的客戶。

**兩個必要條件：**

| 條件 | 意思 |
|---|---|
| **Target Compatibility** | 公司能否為目標客戶創造 superior value？ |
| **Target Attractiveness** | 這些客戶能否為公司創造 superior value？ |

雙向：**Attractiveness 決 priority，Compatibility 決 value**。是動態的循環。

### Tactical Targeting（How）

辨識「用什麼方式接觸到這些 strategically important 客戶」。三步驟：^[extracted Ch06 p.18-20]

1. **Defining the customer profile** — 四類因子（Demographic / Geographic / Behavioral / Psychographic）
2. **Aligning customer value and customer profile**
   - **Effectiveness**（有沒有打到對的人）
   - **Efficiency**（用最少資源打到）
   - 工具：contingency table、chi-square test
3. **Bringing segments to life — [[concepts/customer-persona]]**

## Target Compatibility 細節

公司在滿足目標客戶需求上 outdo competition 的能力。**六項資源來源：**^[extracted Ch06 p.12-13]

1. Business infrastructure
2. Access to scarce resources
3. Skilled employees
4. Technological expertise
5. Strong brands
6. Collaborator networks

對應 [[concepts/value-chain]] 與 [[concepts/VRIO-framework]] 的內部資源觀。

### Core Competency 三條件

Compatibility 的最深層：^[extracted Ch06]

1. 是 competitive advantage 的來源，**對 perceived customer benefit 有顯著貢獻**
2. **可以應用在多個市場**
3. **競爭者難以模仿**

詳見 [[concepts/core-competency]]。

## Target Attractiveness 細節

兩大類 value：^[extracted Ch06 p.15-17]

### Monetary Value

```
Monetary Value = Customer revenues − Costs of serving customers (yield)
```

### Strategic Value（非直接金錢，但策略上重要）

| 類型 | 意思 |
|---|---|
| **Social value** | 病毒行銷、WOM、branding effect |
| **Scale value** | 規模 / 學習曲線推動 |
| **Information value** | 市場情報 / 技術 spillover |

教師批註案例：**TSMC 鳳凰城廠** → 美國國防（information value）；**TSMC 德國廠** → 歐洲下一代電動車 / 自駕車（strategic value）；**鴻海 MIH 電動車開放平台** → monetary value。^[inferred from instructor annotation]

## Multiple-Segment Targeting 兩條路

當鎖定多個 segments：^[extracted Ch06 p.22]

| 策略 | 內容 | 案例 |
|---|---|---|
| **Product specialization** | 一種產品打多個市場 | 通用電腦廠商 |
| **Market specialization** | 服務一個市場的所有產品需求 | Hallmark（賀卡 + 多周邊產品給賀卡市場） |

P × M 矩陣視覺化。

## Single-Segment Targeting = Niche Marketing

只鎖定一個 segment：^[extracted Ch06 p.21]

範例：**Allegiant Air**（廉價航空、低密度航線）— 服務「想去小城市的價格敏感旅客」這個 niche。

## Source 反例 / 質疑

- **Mass customization 與成本邊界** — Kotler 沒給「多大規模 + 多深 customization」的可行性條件。^[ambiguous]
- **Strategic value 的可測量性** — Social / Scale / Information value 都很抽象，source 沒給量化方法。^[ambiguous]
- **One-to-one approach 的隱私 / 規模經濟反論** — source 未提。^[inferred — 隱含批評]
- **教師批註指出 core competency 判斷的灰區**：「有競爭力 ≠ 有核心競爭力」、「沒有核心技術 ≠ 沒有核心競爭力」（如 Moderna）— 三條件其實有判斷模糊地帶。^[inferred from instructor annotation]

## Jason 觀察：醫療 AI 的 Targeting

EBM PACS / AI 的 strategic targeting：^[inferred — Jason 個人延伸]

**Target Compatibility 評估**：
- EBM 在「對台灣放射科 workflow 的深度理解」這項超越國際大廠
- 但在「全 modality 覆蓋」這項輸給 GE Edison

**Target Attractiveness 評估**：
- 醫學中心 monetary value 大但 sales cycle 長
- 區域醫院 monetary value 小但 scale value 大（部署數量 → 學習效應）
- 教學醫院 information value 高（研究合作 + KOL 養成）

**推論：先打教學醫院（高 information + scale value）+ 同步耕醫學中心（高 monetary value）**，避開全打區域醫院的 commoditize 戰場。

**Targeting 策略**：Niche-then-expand — 先深耕「Sectra PACS + 教學醫院 + 神經影像」三層交集 niche，再橫向擴展。

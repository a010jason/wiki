# 薪酬系統結構

## 一句話

Total Rewards = **直接薪資 + 變動薪 + 福利 + 工作本身**。設計重點不是「給多少」而是「怎麼讓四塊組合的訊號與公司策略對齊」。

## 薪資基礎四個 anchor

教師補充 p.7-11 列出薪資設計的四個基礎，每個都暗藏一個 trade-off：

| 基礎 | 邏輯 | 問題 |
|---|---|---|
| **工作內容**（job content） | 同工同酬 | 工作內容變化難量化 |
| **技能 / 知識能力**（skill / competency） | 能力強付高薪 | 跨組織技能定價如何？ |
| **年資**（seniority / tenure） | 久任厚待 | 年資 ≠ 績效，產生年資溢價陷阱 |
| **工作評價**（job evaluation） | 用系統化方法給職位定分 | HAY Points 系統最知名 |

^[extracted]

教師批註多次提問「**跨組織可能造成的影響是什麼**」— 暗示薪酬基礎在跨公司比較時容易失真，HR 不能只看內部公平、要兼顧外部市場。^[inferred from instructor annotation]

## HAY Points（工作評價系統）

教師補充 p.10 點到 **HAY Method** — 1943 由 Edward N. Hay 發明的系統，至今仍是國際大型企業最常用的職位定價工具：

評估維度（教師簡寫，原版三大維度）：

| HAY 三維 | 評估內容 |
|---|---|
| **Know-how**（職能、複雜度） | 知識深度 + 廣度 + 管理範圍 |
| **Problem Solving**（問題解決） | 思考環境的複雜程度 + 思考挑戰程度 |
| **Accountability**（責任） | 行動自由度 + 對組織影響的程度 + 對結果負責的金額大小 |

^[inferred] （教師補充列出「知職的型態與複雜度、管理的員工數、負責薪酬的資產額、工作環境不滿的情況」對應到 HAY 各維度）

**Implication**：HAY 把職位拆成 points → 用 market survey 把 points 換成薪資 → 確保「同等貢獻的職位拿同等薪資」（內部公平）+「對外有競爭力」。

## 矽谷案例（教師多次引用）

| 公司 | 薪資結構特徵 |
|---|---|
| **Facebook** | 資深工程師 ~132,000 USD base + RSU + bonus；強 RSU 比例 |
| **Google** | 階梯式 L3-L9 等級；強 Total Compensation 透明度 |
| **Amazon** | base 偏低、4 年 vesting 高 RSU；前 2 年靠 sign-on bonus 平衡 |
| **Microsoft** | Young FTE（社會新鮮人 fast track） |
| **Huawei** | 自有「薪酬評價系統」對應職等 |

^[extracted]

教師暗示**矽谷模式 ≠ 台灣本地** — 矽谷靠 RSU 把員工綁定 4 年；台灣多半靠分紅 / 年終 / 績效獎金，員工流動性更高。^[inferred]

## 獎金三型

教師補充 p.12-14 列出 incentive 三大類：

| 類型 | 機制 | 例子 |
|---|---|---|
| **佣金**（commission） | 按件 / 次數 / 金額比例計酬 | 業務員、保險、不動產 |
| **分紅**（profit sharing） | 年度為基礎，可現金 / 股票（ESOP） | 年終分紅、員工持股 |
| **工作獎金 / 激勵**（spot bonus） | 即時 / 短期 / 特定行為獎勵 | sign-on、retention、project completion |

^[extracted]

**ESOP（Employee Stock Ownership Plan）**：員工持股計畫是分紅的最知名形式，把員工與股東利益綁定（agency theory 解決方案）。^[inferred]

教師批註提問：「**調薪是否能有效激勵？年終獎金能否取代月薪？**」— 暗示獎金與固定薪有不同的 motivation 機制（[[concepts/expectancy-theory]] / [[concepts/equity-theory]]），不可互相替代。^[inferred from instructor annotation]

## 福利四類

教師補充 p.15-20 把福利拆成四大類別：

| 類別 | 例子 | 目的 |
|---|---|---|
| **經濟性福利** | 勞保 / 健保 / 公保 / 團保 / 退休金 / 失業給付 | 法定下限 + 風險共擔 |
| **社會性福利** | 員工餐廳 / 租屋仲介 / 福利社 / 醫療室 / 體檢 / 托兒所 / 圖書室 | 生活便利、社群感 |
| **健樂性福利** | 體育活動 / 社團 / 樂齡興趣班 / 運動器材 / 旅遊 / 電影音樂欣賞 | 身心健康、文化 |
| **工作本身福利**（內在福利） | 自主性 / 晉升機會 / 挑戰性 / 任務完整性 / 教育訓練 / 彈性上下班 / 工作分享 / 遠距工作 | **這類最強 + 最被低估** |

^[extracted]

教師暗示**第四類 = motivation 真正的核心**（呼應 [[concepts/job-characteristics-theory]] JCM 五維 + Herzberg 雙因子理論的 motivator 端），但企業多數把資源砸在前三類（保健因子 = hygiene factor）。^[inferred]

### 自助式福利（cafeteria-style benefits）

教師補充討論的兩刃：

| 優點 | 缺點 |
|---|---|
| 員工自主性高 → 激勵性提升 | 集體議價能力降低 → 採購成本上升 |
| 投其所好減浪費 | 行政成本增加（IT 系統 + 員工選擇支援） |

^[extracted + inferred]

實務上**大公司多採固定 + 彈性混合**，避免 cafeteria 的 admin overhead。

## 公平、保密、與內部比較

教師補充提問**薪資公開性的兩難**：

- **完全保密** → 員工不知道 market value、降低談判力
- **完全公開** → 公平感知建立，但激發內部「我為什麼比 X 少」的比較怨懟

實務多走「**級距公開 + 個別保密**」（band 透明、個人薪資隱藏）。^[inferred]

## 對接其他框架

- **vs [[concepts/equity-theory]]** (Adams)：薪資公平感是 equity theory 的核心應用領域
- **vs [[concepts/expectancy-theory]]** (Vroom)：薪酬作為 reward 在 instrumentality 鏈中的角色
- **vs [[concepts/job-characteristics-theory]]** (JCM) / [[concepts/job-satisfaction]]：工作本身福利的理論基礎
- **vs [[concepts/MBO]]** / [[concepts/forced-ranking]]：績效評估 → 薪酬的對接機制
- **vs [[concepts/forced-ranking]]**：GE 強制 20/70/10 的薪酬差距設計

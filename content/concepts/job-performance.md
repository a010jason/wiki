# Job Performance

Colquitt-LePine-Wesson 教科書定義：「the value of the set of behaviors that contribute, either positively or negatively, to organizational goal accomplishment」—— 是**行為**本身、不是結果。^[extracted]

在 OB Integrated Model 中位於 **Individual Outcomes**（另一個是 Organizational Commitment），由 individual mechanisms（[[concepts/organizational-behavior]] motivation / satisfaction / stress 等）驅動。

## 行為 vs 結果之爭

教科書直接提問 "What's good/bad about this distinction"：^[extracted]

| 取 behavior 定義 | 取 outcome 定義 |
|---|---|
| ✅ 排除運氣、市場景氣等員工不可控因素 | ✅ stakeholder 真正在意的是結果（業績、bankruptcy 次數） |
| ❌ 高 effort + 壞結果該怎麼算？ | ❌ 把員工綁在不可控變數上 |

實例：JPMorgan Chase 定義 performance = 核心職務 + 公司流程支持 + **不**違反 policy/regulation —— 三項全是 behavior 而非單純 outcome。^[extracted]

爭議錨點：Donald Trump 賭場 1991-2009 六次 bankruptcy 但個人從未破產 —— performance 該如何評？教材自己留作 open question。^[extracted]

## 三維分解（章節骨幹）

```
Job Performance =
  Task Performance（核心職務）
  + Citizenship Behavior（角色外正向）
  − Counterproductive Behavior（角色外負向）
```

### Task Performance 三亞型

**展開頁：[[concepts/task-performance]]** — Routine / Adaptive / Creative 完整分解 + Improv 訓練法 + Pixar/Disney 四原則。

| 亞型 | 條件 | 例 |
|---|---|---|
| **Routine** | 穩定環境、well-known response | 飛安示範、烤鴨 SOP、GM Lordstown 車門佈線 |
| **Adaptive** | novel / unusual circumstances | Sully 哈德遜河迫降、JAL 516 全員撤離 |
| **Creative** | novel **AND** useful | Pixar atrium 設計、Southwest 唱版安全示範 |

Pulakos 8 維 adaptive performance：handling emergencies、handling work stress、creative problem-solving、dealing with uncertainty、learning new tasks/tech、interpersonal adaptability、cultural adaptability、physically oriented adaptability。^[extracted]

### Creative Performance 的雙條件

**Novel + Useful**。Creative ideas 不一定被 implement，所以教材主張同時看**行為**與**結果**。^[extracted]

Pixar Steve Jobs 設計總部 atrium 把 mailbox / 會議室 / 廁所集中中央，**強迫**員工跨團隊互動 —— 物理空間 → creative behavior 的工程化。

### Citizenship Behavior（OCB）

[[concepts/organizational-citizenship-behavior]]：自願性、角色外、貢獻 psychological / social environment。五子向度：Helping、Voice、Civic Virtue、Boosterism、Sportsmanship（包容）。^[extracted]

**Boundary**：[[concepts/citizenship-fatigue]] —— OCB 不是無限可拉的彈簧。

### Counterproductive Behavior（CWB）

**展開頁：[[concepts/counterproductive-workplace-behavior]]** — Robinson-Bennett (1995) 二維分類（嚴重程度 × 對象）形成四象限。

**重要 boundary**：CWB 與 task performance **僅弱負相關** —— 高績效員工也可能是 bad apple。^[extracted]

## Job Analysis（識別 task performance 的方法論）

**展開頁：[[concepts/job-analysis]]** — 三步驟方法論 + O*NET 工具 + 教學簡化版四步驟。

三步驟簡述：^[extracted]
1. 列出活動清單（observation / survey / interview）
2. SMEs 依 importance + frequency 打分
3. 高分活動保留 → 用於 training learning objectives 與 performance evaluation

→ 連到 JD（job description）/ JS（job specification）/ 招募 / training / PM。

## AI 對 Job Performance 的 levelling 效應

Choi et al. 法學院實驗：GPT-4 對 bottom-class 學生提升大；對 **top-class 學生反而拉低 grade**。教材稱「AI is the great equalizer」。^[extracted]

→ Jason PM 視角：醫療 AI 在臨床端可能有相同分布效應 —— 對資淺放射師輔助大、對資深放射師可能是干擾。值得後續 synthesis。^[inferred]

## Performance Management 工具（5 種）

| 工具 | 強項 | 弱項 | 展開頁 |
|---|---|---|---|
| **MBO**（Drucker / Intel） | 客觀、cascading 順暢 | 只看結果不看行為 | [[concepts/MBO]] |
| **BARS** | 行為錨點化，直接評行為 | 設計成本高 | — |
| **360-degree feedback** | 多源、適合 development | 不適合 reward | — |
| **Social networking systems**（Accenture Performance Multiplier、Rypple） | real-time | 文化變革難 | — |
| **Forced Ranking**（GE / Jack Welch） | 短期 16% productivity 提升 | 3-4 年降到 6%、10 年趨近 0；引發 lawsuit | [[concepts/forced-ranking]] |

Tesco 用 360-degree 配合 'Leaders at Tesco' training；Accenture 從 annual review 轉到「performance achievement」real-time feedback。^[extracted]

更上層的 evaluation vs development 兩條路線分類見 [[concepts/performance-management]]。

## 跨文化差異

GLOBE 研究：^[extracted]
- 高 assertiveness + 高 uncertainty avoidance + 低 in-group collectivism → 偏用 **formal** appraisal（美國）
- 高 power distance + 高 collectivism → 評分系統性**寬鬆**（多數亞洲）

Korean 員工 majority 質疑自身 performance evaluation 的效度 —— formal appraisal 工具在集體主義文化效力打折。

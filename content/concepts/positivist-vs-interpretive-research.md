# Positivist vs Interpretive Research

## 對照表 ^[extracted]

| 維度 | Positivist | Interpretive |
|---|---|---|
| 取向 | 演繹（理論出發，由數據解釋理論） | 歸納（資料出發） |
| 目的 | Theory / Hypothesis **testing** | Theory **building** |
| 典型 method | Laboratory experiments、survey research | Action research、ethnography、phenomenology |
| 資料類型 | 預設 quantitative，可含 qualitative | 預設 qualitative，可含 quantitative |
| Reality 假設 | objective view of reality | subjective interpretation |
| 對 generalization 期待 | 找 generalized patterns | 找深度脈絡，generalize 受限 |
| 研究者位置 | objective observer（外） | participant（內） |
| 分析時序 | data collection → analysis 分開 | data collection + analysis 同步疊代 |

教師中文眉批：「演繹：理論出發，由數據解釋理論」「歸納：資料出發」

## 重要澄清：不等同 quantitative/qualitative ^[extracted]

> 「these methods are incorrectly equated with quantitative and qualitative research」

- Positivist 也可用 qualitative data（如 content analysis 算頻率）
- Interpretive 也可（且應該）用 quantitative data
- 教師範例：Eisenhardt 高速決策研究中其實也用 numeric data（決策耗時、alternatives 數、conflict survey）→ mixed-mode 強化詮釋

## Bhattacherjee Ch12 對 Interpretive 的補充 ^[extracted]

Interpretive 與 positivist 的根本差異不在 method 而在 **paradigm**：

| 維度 | Positivist | Interpretive |
|---|---|---|
| **Ontology** | 客觀單一 reality | 多元、受脈絡塑造 |
| **Epistemology** | 客觀觀察、外部測量 | 必須在 socio-historic 脈絡中、調和多方主觀詮釋 |
| **Sampling** | Random sampling | **Theoretical sampling**（按理論需要選 site） |
| **研究者** | Objective observer | **研究者是研究的一部分** |
| **分析** | Reduction（拆元件） | **全方位脈絡分析** |
| **Rigor 標準**（Lincoln & Guba 1985） | Reliability / Internal / External / Objectivity | **Dependability / Credibility / Transferability / Confirmability** |

## Lincoln & Guba (1985) 的 Naturalistic Inquiry 四準則 ^[extracted]

替代 positivist rigor 標準：

| Positivist 標準 | Interpretive 對應 |
|---|---|
| Reliability | **Dependability** |
| Internal validity | **Credibility** |
| External validity | **Transferability** |
| Objectivity | **Confirmability**（inter-subjectivity） |

## 三大 Interpretive Designs ^[extracted]

| Design | 內容 |
|---|---|
| **Case research** | 對單一 / 少數 sites 做深度研究 |
| **Action research** | Susman & Evered (1978) — 五階段 cycle（diagnosing / action planning / action taking / evaluating / learning），應至少跑兩輪 |
| **Ethnography** | 8 個月-2 年 immersion，文化脈絡研究 |
| **Phenomenology** | Giorgi & Giorgi (2003) — interview → 找 "units of significance"（felt-space、felt-time） |

## Interpretive Research 的挑戰 ^[extracted]

教師明列：
- Time + resource intensive
- 需要訓練有素的研究者
- Participants 可能有隱藏議題
- 難 replicate / generalize
- 有時答不出原研究問題

## Bhattacherjee 全書的立場 ^[extracted]

整本書仍是 **positivist functionalist** 取向（Ch3：「Most traditional research tends to be deductive and functionalistic in nature」）。

但對 interpretive research 給予明確正當性（Ch12 有獨立章節，Ch13 詳述 qualitative analysis 技巧）。

→ Bhattacherjee 的「mixed-mode 推薦」是試圖在兩 paradigm 間搭橋。

## 對 PM / 醫療 AI 應用 ^[inferred]

PM 工作的 paradigm tension：

| Stakeholder | 預設 paradigm |
|---|---|
| Engineering / Data | Positivist（A/B test、metric） |
| Designer / UX | Interpretive（user research、ethnography） |
| 監管（FDA） | Positivist（clinical evidence） |
| 臨床醫師（採用 AI 的人） | Interpretive（workflow fit、professional identity） |

優秀醫療 AI PM 必須能在兩典範間翻譯 — 把 ethnographic insight 變成 testable hypothesis，把 RCT 結果 contextualize 回臨床敘事。

## 限制 ^[inferred]

- 二元對立過度簡化 — pragmatist / critical realist / constructionist 等中間立場被忽略
- 在實務上純 positivist 或純 interpretive 很少見（hybrid 是常態）
- 「mixed-mode 較佳」的主張本身仍預設 positivist 評判（在 interpretive paradigm 內，「結果是否一致」不是關鍵）

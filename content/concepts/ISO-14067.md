## TL;DR

ISO 14067 為**產品層級**的溫室氣體足跡盤查標準，採生命週期觀點（LCA）涵蓋**原料取得 → 製造 → 配銷 → 使用 → 廢棄**全程。與 [[concepts/ISO-14064-1]]（組織盤查）互為姊妹標準。

## 生命週期五階段

```
原料取得 → 製造 → 配銷 → 使用 → 廢棄
   ↑         ↑      ↑      ↑      ↑
Cradle    Gate   Distribution Use  Grave
```

## 案例：500 mL 牛奶碳足跡

```
500 mL × 2.48 kgCO2e/L × GWP=1 = 1.24 kgCO2e
```

## 案例：Adidas 鞋類碳標籤

| 年份 | 碳排放 | 變化 |
|---|---|---|
| 2014 | 38 gCO2e | baseline |
| 2017 | 34 gCO2e | -10.5% |
| 2020 | 32 gCO2e | -15.8% |

## 資料品質評估（DQR）

5 維度評分：
- **時間性**（資料新舊）
- **地理性**（地域代表性）
- **技術性**（製程代表性）
- **可靠性**（來源權威）
- **完整性**（涵蓋範圍）

DQR 總分 ≥ 1.3 為高品質。

## TL;DR

傳統會計只反映「正產品」（賣得出去的產品）成本，**忽視「負產品」（廢棄物、污染、碳排）成本**，導致淨利虛高。永續會計透過導入**負產品成本 = 材料成本 + 系統成本 + 能源成本 + CO2 處理成本**，將環境外部性內部化進損益表與資產負債表。

## 損益表差異（示例）

| 項目 | 傳統會計 | 永續會計 | 差額 |
|---|---|---|---|
| 營收 | 5,000,000 | 5,000,000 | - |
| 銷貨成本（正產品） | 3,200,000 | 3,200,000 | - |
| **負產品成本** | 0 | 246,000 | -246,000 |
| 營業費用 | 664,000 | 664,000 | - |
| **淨利** | **1,136,000** | **890,000** | **-246,000 (-21.7%)** |

來源：[[references/esg-lecture-corpus]] / CarbonAccounting-Zhang (p.31-37) 張民忠教授

## 三大會計處理法（碳權交易）

| 方法 | 邏輯 |
|---|---|
| **完全市場價值法** | 配額視為資產（公允價值），市場價格波動進損益 |
| **初始市場價值法** | 配額視為資產（取得成本），不隨市場波動 |
| **名目金額法** | 配額不入帳，僅揭露在附註 |

## 資產負債表內部化

- 碳權持有 → 資產（金融資產 / 無形資產）
- 排放超標 → **環境負債**（需購碳權義務）
- 環保罰款 → 或有負債

## ISO 14064 / 14067 與會計連動

- 盤查數據 → 排放清冊 → 排放成本 → 損益表
- 內部碳價（ICP） → 跨部門碳預算 → 投資決策

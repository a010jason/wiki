# Task Performance（任務績效）

## 定義

Task performance ＝ **將組織資源轉化為產品 / 服務的行為**，包含「job description 上寫的事」。^[extracted]

是 [[concepts/job-performance|Job Performance]] 三維度中最直覺、最易測量的一支。識別方法 → [[concepts/job-analysis]]。

## 三個子類

教科書把 task performance 拆成 routine / adaptive / creative 三型（Colquitt Ch2 p.24）：^[extracted]

### Routine Task Performance

對 **predictable / well-known** 任務的標準化、重複式反應。

- **特性**：response 已標準化，環境變動小，可累積百年 know-how
- 例：
  - **航空公司起飛前的安全示範**（seatbelt 設計近百年未變，1920 即定型）^[extracted]
  - **GM Lordstown 裝配廠女性員工裝車門線**（以 number and quality of work 量測）^[extracted]
  - **全聚德烤鴨**（Beijing 1864 至今）— routine 累積 culinary heritage 的代表 ^[extracted]

### Adaptive Task Performance

對 **novel / unusual / unpredictable** demand 反應的「thoughtful response」。Pulakos et al. 列出八類：^[extracted]

1. Handling emergencies / crisis
2. Handling work stress
3. Solving problems creatively
4. Dealing with uncertain / unpredictable situations
5. Learning new tasks / technologies
6. Demonstrating interpersonal adaptability
7. Demonstrating cultural adaptability
8. Demonstrating physically oriented adaptability

#### 案例集

- **JAL Flight 516 / Tokyo Haneda（2024-01-02）**：撞地震救援機後 **379 人全員 safely evacuated**，被視為 adaptive task performance under emergency 的當代代表案 ^[extracted]
- **Air France 358 / Toronto overrun（2005-08-02）**：309 人全部生還、12 重傷，highly trained flight attendant 的 adaptive 表現是關鍵 ^[extracted]
- **US Airways 1549 / Hudson River（2009-01-15）**：Sully 案，撞 Canada geese 失全部引擎動力 ^[extracted]
- **Starbucks barista secret note on cup（2023-10-20）**：barista 觀察到女顧客被陌生男子騷擾，杯上寫「Are you okay? Do you want us to intervene? If you do, take the lid off the cup.」屬 interpersonal adaptability + creative problem solving ^[extracted]
- **Ohio 911 dispatcher / pizza order（2019-11-23）**：dispatcher 辨識出「打 911 點 pizza」的女子其實在通報家暴 ^[extracted]

#### Better Adaptive Performance Through Improv

教科書用整整 9 張投影片提倡 **improv（即興劇場方法）作為 adaptive performance 訓練法**。^[extracted]

- 採用名單：American Express、Dupont、Google、Hilton Worldwide、PepsiCo、Major League Baseball
- 核心技巧：**"Yes, and"** — 先 affirm 客戶需求（Yes）、再以提問加深對話（and），讓 upsell 變得自然而非強迫推銷
- 反主流原則：**"Don't plan; just listen"** — 反對「先 plan 再執行」邏輯；planning while customer talking 會導致 short / impatient answer 並 miss 重要資訊

### Creative Task Performance

**Novel + Useful** 雙條件同時成立的構想或產出。^[extracted]

- 創意 idea 不一定被執行 → 必須同時看 creative **behaviors** 與 creative **outcomes**
- 兩種展現：
  - **產品本體創新**：3M Post-it、Queentex 泳衣、小林眼鏡 × NBA 籃球造型眼鏡盒、Star Wars × 7-ELEVEN 白兵物流箱
  - **服務情境創新**：Southwest Airlines flight attendant 機艙樂團 / 安全示範幽默

#### Magic in the Workplace — Pixar / Disney 釋放創意人才四原則

教科書（p.51–55）給出 organizational mechanism 層面的處方：^[extracted]

1. **Creative behavior 從 creative work spaces 開始**（空間設計驅動自發互動）
   - Steve Jobs 在 Pixar 把郵箱、會議室、cafeteria、**特別是廁所**置於 central atrium，迫使員工 casual interaction → "good things happen"
2. **Putting fun back into work**（用 culture of fun 取代 monotonous drone）
3. **對齊個人 dream 與公司 dream**（fun 與 common goal/vision 並存）
4. **Allow personalized workspaces**（hammocks / pod-shaped rooms / slides / library lounges + 月度 "most creative workspace" contest）
5. **Celebrate**（用 birthday / anniversary / graduation 提振 morale）

#### DEWA Afkari 平台案

Dubai Electricity and Water Authority 內部 idea platform：^[extracted]
- 2023 年收到 **6,235** 個 innovative ideas
- **85%** of approved ideas 已實施

## Boundary Conditions / 待批判

- Routine task 的 boundary：環境變動加劇後 routine training 不夠，需轉 adaptive ^[inferred]
- Adaptive performance 在高度規範產業（核電、麻醉、放射科 reporting）是否反而是 risk？source 未討論 ^[ambiguous]
- Improv training ROI 證據？source 只列採用公司名單，**沒給效果數據** ^[ambiguous]
- "Fun in average workplace is realistic?" — source 自己拋出這個 boundary question（p.53），緩解前提是「對齊個人 dream 與公司 dream」，但未提供量化證據說明此前提如何達成
- Pixar 廁所中央化軼事：anecdotal evidence，無同行評審研究支持「空間設計 → 創意產出」因果鏈 ^[inferred]

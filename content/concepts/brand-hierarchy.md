# Brand Hierarchy & Portfolio Strategies

## What It Is

| 概念 | 定義 |
|---|---|
| **Brand Hierarchy** | 公司品牌與產品/服務品牌的關聯方式與相互關係結構 |
| **Brand Portfolio** | 公司在特定類別或市場區隔中提供的所有品牌與品牌線的集合 |

^[extracted Ch10 p.17-18]

意涵：Hierarchy 是**縱向結構**（公司 → 產品線 → 個別 SKU），Portfolio 是**橫向集合**（同一公司多少個 brand）。

## 三大策略

Kotler 列出三條 portfolio 策略線：^[extracted Ch10 p.19]

### 1. House-of-Brands（品牌之家）

多個**區隔獨立**的品牌，公司名通常不顯眼。

範例：
- **P&G**：Tide / Pampers / Gillette / Olay / Crest（消費者不一定知道是 P&G）
- **Unilever**：Dove / Knorr / Lipton / Magnum
- **United Technologies**：Pratt & Whitney / Otis / Carrier

策略邏輯：
- 不同 brand 對應不同 segment / positioning，避免 cannibalization
- 一個 brand 失敗不影響其他 brand
- 收購整合靈活
- **代價**：行銷支出分散，無法共享 brand equity

### 2. Branded-House（品牌之屋）

**單一主品牌**，下方所有產品都掛同名。

範例：
- **Apple**：iPhone / iPad / Mac / Watch / AirPods
- **Google**：Search / Maps / Drive / Photos
- **FedEx**

策略邏輯：
- 所有產品共享 brand equity
- 行銷投資高度集中，效率高
- **代價**：一個產品出包影響全 brand

### 3. Sub-Brand Strategy（子品牌）

主品牌 + 子品牌的**層級化**結構。

範例：
- **Toyota / Lexus**：Toyota 是 mass，Lexus 是 luxury
- **Marriott**：Marriott / Courtyard / Ritz-Carlton / Bulgari Hotels
- **VW Group**：VW / Audi / Porsche / Lamborghini / Bentley

策略邏輯：
- 兼顧 House-of-Brands 的區隔與 Branded-House 的效率
- 子品牌可向上汲取主品牌信用，又能維持獨立 positioning
- **代價**：管理複雜度高

## 三策略比較

| 維度 | House-of-Brands | Branded-House | Sub-Brand |
|---|---|---|---|
| 行銷效率 | 低（分散） | 高（集中） | 中 |
| 風險分散 | 高 | 低 | 中 |
| 跨 segment 靈活度 | 高 | 低 | 中-高 |
| 管理複雜度 | 高 | 低 | 中 |
| 適用產業 | FMCG、多元集團 | 科技、單焦點 | 汽車、旅館、奢侈品集團 |

## BCG Matrix 與 Brand Portfolio

教師批註：「**Markops 品牌屬於哪個類別？Cash Cow**」— 提示把 BCG Matrix（市佔 × 成長率）套到 brand portfolio：^[inferred from instructor annotation Ch10 p.18]

| BCG | 對應 brand 策略 |
|---|---|
| **Star** | 重金投資、擴張 |
| **Cash Cow** | 維持、收割現金；用來資助 Star 與 Question Mark |
| **Question Mark** | 評估是否拉成 Star，或撤退 |
| **Dog** | 收割後撤退 |

意涵：Portfolio 不是平等對待所有 brand；用 BCG 識別現金流關係。

## Brand Crisis Management

當 portfolio 內某 brand 出包，Kotler 列四步驟：^[extracted Ch10 p.24]

1. **Empathy（同理心）** — 立刻承認受影響者的損失
2. **Values（價值觀）** — 重申 brand 的長期承諾
3. **Strategy（策略）** — 公開具體修補計畫
4. **Innovation（創新）** — 用危機為契機，重新定義

教師批註：「**D-Link 危機 — 缺失什麼？**」— 提示讀者識別 D-Link 在危機中缺了哪一步。^[inferred from instructor annotation Ch10 p.16]

## Source 反例 / 質疑

- **三策略的選擇條件不明**：source 沒給「什麼產業該選哪一個」的明確判準。^[ambiguous]
- **科技平台（Amazon、Google）混用三策略**：Amazon Prime / Kindle / Echo / AWS 同時呈現 sub-brand 與 branded-house 邏輯。^[inferred — Jason 觀察]
- **奢侈品的 sub-brand 矛盾**：LVMH 集團是 house-of-brands（每個 brand 獨立），但每個 brand 內部又是 branded-house（強單一性）— 同公司內混用兩策略。^[inferred]

## Jason 觀察：醫療 AI 廠商的 brand portfolio

EBM、Sectra、AI 影像新創的常見模式：^[inferred — Jason 個人延伸]

- **小型新創**：通常 branded-house（產品 = 公司名），因為資源有限
- **PACS 廠商**：sub-brand（Sectra OneScreen、Sectra Vue Premier）— 主 brand 是 PACS，子品牌是 AI 模組
- **大型 multi-product**：house-of-brands（Philips IntelliSpace / IntelliPACS / IntelliVue）

問題：醫療 AI 廠商的 brand 受眾分裂（醫師 vs IT vs 採購）— 不同受眾對 hierarchy 的感知不同；同 brand 對 IT 是「整合產品線」，對醫師可能只是「不熟悉的子品牌」。

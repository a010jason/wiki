## TL;DR

員工認股權契約（ESOP, Employee Stock Ownership Plan / Option）讓員工以優惠價格購買公司股票，目的是**激勵長期承諾與股東利益對齊**。台灣公司法第 167-2 條訂定，配合減資再增資、虧損撥補機制使用。

## 法源

| 法條 | 內容 |
|---|---|
| **公司法 167-2** | 員工認股權契約 |
| **公司法 167** | 股份回購限制（庫藏股） |
| **公司法 168** | 減資程序與虧損撥補 |

## 操作流程

```
1. 減資（虧損撥補 / 退還股東）
2. 發行認股權（價格、行使期、歸屬條件）
3. 員工達成績效 / 服務年限 → 行使
4. 增資發放新股給員工
```

## 與美國 ESOP 對比

| 維度 | 台灣 | 美國 |
|---|---|---|
| **稅務優惠** | 一般所得稅 | 大量稅務優惠（員工持股信託） |
| **規模** | 小（單一公司用為主） | 大（可作為退休金替代） |
| **典型用途** | 高科技、新創 | 製造業傳承 + 全產業 |

## 短視激勵的批判

- **CEO 短視炒股**：認股權鼓勵推升短期股價，可能犧牲長期投資
- **稀釋風險**：員工大量行使後股本擴張
- **解鎖時程設計**：4 年逐步歸屬（vesting）是業界慣例

## 對應的減資再增資

- **減資**（虧損撥補）：把累積虧損沖掉，為新發股「清地」
- **再增資**（員工認股）：以新股給員工
- **舊股東脫身**：減資後股本變小，舊股東持股比例不變但帳上虧損消除

## 案例

- **Google、Meta**：複數表決權股 + 員工認股權，鞏固創辦人控制 + 激勵員工
- **台灣新創**：常用減資再增資 + 員工認股權吸引人才（[[references/corporate-governance-lecture-corpus]] / Gov-2025-03-14）
